# 巨人城 · 设定工作稿

主人 10/27：这周把巨人城内部的设定完善好——从世界观角度，让它成为一座**可信的城市**。这份是讨论记录：已有设定（出处）、还缺什么、每次讨论定下来的东西。**只记主人定的和手册里写了的；没定的放「待讨论」，不替主人编。**

## 一、已有设定（出处：《回火 主持人手册》经验勘误版、NPC.docx、游戏里的数据）

### 来历
- 巨人到来前，角鳞星只有一片够两个部落的小绿洲：凯拉斯农耕、鳞灰族采果，互相交换、切磋魔法与武艺。巨人带来远超承载力的人口，**绿洲被建成巨人城**，其余种族被挤进沙漠。（手册 第 4 页）
- 角鳞星矿产丰富是因为巨人到来前长期频繁的陨石撞击；天网建成后天上几乎不再落陨石。

### 尺度与地理（手册 第 6 页；world-travel.js）
- 核心区直径约 18 km（半径约 9.0 km）；外城区是厚约 600 m 的贫民窟环（外半径约 9.6 km）；外城区之外直接是沙漠。
- 城内步行 4–5 km/h，绕路系数 1.4。**道路极宽**（巨人 6–8 米高）。巨人车烧油。
- 北边是星际港口；方向上通往第一矿场、沙穹赌场、太阳能板群。
- **玻璃穹顶**：平日常开，漠汛（一年两次、每次 22 天的全球沙暴）期间关闭，全面防护。外城区只有巨人发的金属挡风板。

### 边界：甄别关（手册 第 6–7 页）
- 一整圈光滑无缝、近乎反光的浅色合金墙，砌在外城区和核心区交界线上，完整绕城一周。从外城区任何角落抬头都看得到。
- 只在通往星际港口、第一矿场、沙穹赌场、太阳能板群的几条主干道上各开一座关卡（如「甄别关·星港段」「甄别关·一矿段」）。
- 决策者是后台算法：排队 → 身份核验（携讯机 / 植入体扫描，比对雇主担保或正式邀约编码）→ 事由分类（只认受雇于城内机构、医疗陪同、指定物资运送等极少数事由）→ 物理 / 生物扫描 → 每日配额。没有申诉；可疑者被带去「进一步核实」。
- 有雇主担保的兽人通过率略高；本质上「是不是巨人」决定一切。
- 工厂区 / 产业带大概率在外城区或紧贴外城区外缘、朝沙漠一侧，不用过关。
- 绕开甄别关的唯一路线：季玛提供的污水处理厂地下管道。伪造身份是战略资源。摩尔玛持长期有效通行凭证。

### 管道区黑市（手册 第 7 页）
- 建城时运泥沙的排渣管道，工程后废弃（巨人懒得拆）。紧贴甄别关**内侧**墙根、主要在地下，地表只留坍塌的管道残段做标志和出入口；和下水道局部相连。
- 势力：奥黛女士（最深处、最体面的地下拍卖场）、恩佐（情报，不占地盘）、泽卡尔（管道区与下水道交界）、崔佛（手艺人，来去自如）、亡命之王 / 狂徒（武装变量）。没有人真正统治。

### 社会与经济
- 巨人：6–8 米，无同理心，无家庭，寿命男约 150、女约 200。**蜂巢意识**：情绪诞生瞬间被集体多数稀释、重置（前期只显得冷酷，中期用季玛、散热器部门露出裂缝）。对内**算法分配**经济。
- 触灵：软体，离水一天即死，寿约 300。兽人有公民权益，寿 80–120。类人待遇往往比人类更差。人类平均寿命约 50，日薪约 1500 奎支。
- 物价：500 ml 水 600 奎支。沙穹入场券 5000（门槛低、贷款高，输光的被送去矿场）。
- 「只要能交付足够的租金就可以住在巨人城了」（努尔小时候听巨人说的）。
- 职业：建筑工——巨大的城市中显得微不足道，业务从洗脸台组装到下水道排线。
- 走狗线：爬得越高越能接触指挥官，晋升兑现成通行权限。

### 武装与秩序
- 七指挥官（第九章）：**鎏压 Voltessa 统领巨人城巡逻**（人类，电；雷鸣 + 高压，仪仗即电网）；纷姬（总部护卫 / 巨人城塔）；泽山（巨人空军）。
- 游戏里巨人城的敌人：安保（机器人看守剑 / 枪、巡逻车、自爆小车、巡检浮标、空投蜂群、高压巡逻艇、投料无人机）、警卫队（狼 / 牛 / 蜥蜴队长）、机甲触灵、巨人。区域天气倾向：雷鸣、酸雨、雪、微光。

### 10/27
- 本周目标：巨人城设定完善成可信的城市。地图、设定放进游戏哪里「完善了再说」；鎏压和巡逻队「之后慢慢设计」。
- **定 · 水**：巨人通过星际贸易采购水，补足总量后用污水处理厂循环利用。巨人城里的水并不稀缺。
- **定 · 食物**：城里有专门的农业区，培养高科技基因改造食品，产量很大，城里的食物很不错。外城区的人基本吃巨人制造、派发出去的流食，通过采购窗口购买。

### 10/27（续）
- **定 · 水（续）**：「500 ml 水 600 奎支」是外城区的价格，城内便宜得多。触灵街区缺水通常不可能；但如果污水处理厂被搞垮，触灵街区巨大的水需求会立刻出问题。（和手册「污水处理厂是城市心脏」「缺水唯一能真正威胁统治层自身的地方」对上。）
- **定 · 流食**：在工厂区制作。采购窗口设在外城区的各个点位。价格同规则书（游戏数据里流食 300 奎支一份，`trpg-data.js` / `rogue-data.js`）。
- **定 · 兽人市长**：由巨人选出，被要求绝对服从。对巨人无所谓的事，巨人一般不管；但绝不允许威胁巨人统治体系的事发生，所以市长人选由巨人把控。
- **定 · 兽人居民区**：约占城内 30% 面积，到处都有（不是集中一块）。
- **定 · 首脑议会**：九个巨人是巨人之中能力最强的，由巨人的算法选出。
- **定 · 权力分工**：指挥官们都在巨人统治之下；市政厅只管城内的社会秩序。
