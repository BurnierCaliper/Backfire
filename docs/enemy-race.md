# 敌人种族（设计定稿，2026-10-21）

给有机体的敌人加上种族：种族的**被动**照搬玩家角色的种族特长 / 缺陷，**随机抽种族**的敌人另外按种族的六维修正改数值。
目的：让种族在战斗里有实感，而不只是一个标签；敌人和角色用同一套规则。

规则来源：`docs/AntlerScale · 角色创建规则.docx` 第一步「种族」；换算公式来自 `growth.js · derivedFromAttrs`、`party.js · bareBlockFromDex`。

---

## 1. 哪些敌人有种族

| 敌人 | 种族 | 方式 | 套六维 |
| --- | --- | --- | --- |
| 警卫队队长·狼 | 兽人·狼 | 固定 | 否 |
| 警卫队队长·牛 | 兽人·牛 | 固定 | 否 |
| 警卫队队长·蜥蜴 | 兽人·蜥蜴 | 固定 | 否 |
| 矿场监工 | 兽人·熊 | 固定 | 否 |
| 赤牙 | 犬类人·狼（手册第九章「狼类人」） | 固定 | 否 |
| 蚁型特殊戒备兵种、蚁型特殊剿灭兵种 | 兽人里随机（见第 2 节） | 随机 | 否（见下） |
| 燃气收集机（驾驶员） | 类人里随机 | 随机 | 是 |
| 狂徒（匕首）、狂徒（锤）、强盗头子、亡命之王 | 人类 / 红皮人 / 类人 随机 | 随机 | 是 |
| 巨人 | 暂不定 | — | — |
| 其余（机械、触灵、沙灵、野生、沙漠生物、中立生物、异星生物、古代造物） | 无种族 | — | — |

- **固定种族的敌人不套六维**：设计它们的数值时已经把种族算进去了。被动照样挂上。
- **蚁型兵种不套六维**：兽人五支的六维修正完全一样（体质 +1、耐力 +1、智力 +1），套了只会让整体变强；保持原数值的水平，分支只决定被动。
- **燃气收集机**：有肉体层 = 生物驾驶的机器（README 里写它是「机械」，实装时改掉）。驾驶员的体质只改最内层的肉体，护盾、装甲是机体。

## 2. 随机权重

**盗匪**（狂徒两种、强盗头子、亡命之王）：

| 种族 | 概率 |
| --- | --- |
| 人类 | 60% |
| 红皮人 | 20% |
| 类人 | 20%：犬类人、猫类人、鼠类人、牛类人四个大支各 5%，大支里的小分支再平分（犬 / 猫 / 牛类人的小分支各约 1.7%，鼠、兔各 2.5%） |

**燃气收集机**：类人四个大支各 25%，小分支再平分。

**蚁型兵种**：兽人五支，猫的概率是其余的 1/3——狼、牛、蜥蜴、熊各约 23.3%，猫约 6.7%（「灵巧」让精英很难被打进失衡，所以压低）。

亡命之王是首领，也全部放进随机（作者 10/21 评估过：独狼、威压等都不会伤害游戏体验）。

## 3. 六维换算（只对随机种族、且「套六维」的敌人）

把「全 5 + 种族修正」和「全 5」分别代进角色公式，取差值加到敌人身上：

| 属性 | 角色公式 | 加到敌人的哪里 |
| --- | --- | --- |
| 体质 | 生命 = 体质×2 + 2 + 体质×(等级−1) | **最内层的肉体**（每 ±1：1 级 ±2，之后每级再 ±1） |
| 力量 | 个人 atk = ⌈4 + (力量−5)/2⌉ + ⌈力量×(等级−1)/7⌉ | atk / personalAtk |
| 耐力 | 架势 = ⌈4 + (耐力−5)/2⌉ + ⌊等级/10⌋ | 架势（+1 点 = +1；−1 点向上取整后不变） |
| 敏捷 | 空手格挡 = 30 + (敏捷−5)×5 | 只对本来会格挡的敌人生效（±5% / 点）；大多数敌人没用，作者确认无所谓 |
| 意志、智力 | 坚毅、改造率 | 敌人没有，不换算 |

种族的六维修正（规则表）：

| 种族 | 修正 |
| --- | --- |
| 人类 | 意志 +1、智力 +1（对敌人没有数值变化） |
| 红皮人 | 力量 +1、体质 +1、敏捷 −1 |
| 犬类人 | 体质 +1、敏捷 +1 |
| 猫类人 | 敏捷 +1、智力 +1、体质 −1 |
| 鼠类人 | 敏捷 +1、智力 +1、体质 −1、耐力 −1 |
| 牛类人·牛 / 马 / 羊 | 力量 +2、耐力 +1 / 力量 +1、敏捷 +1、耐力 +1 / 力量 +1、意志 +1、智力 +1 |
| 兽人（五支相同） | 体质 +1、耐力 +1、智力 +1 |

例：狂徒（锤）10 级原本肉体 74、atk 13 → 红皮人 肉体 85、atk 15；猫类人 / 鼠类人 肉体 63。

顺序：**种族 → 个体值波动**（`enemies.js · applyEnemyIV`）。个体值按套完种族之后的数值算。

## 4. 被动（照搬，敌人版）

设计具体敌人时会把被动的影响算进去，所以不另外削弱。战斗里用得上的：

| 种族 | 被动 | 敌人版做法 |
| --- | --- | --- |
| 人类 | 迎难直上：检定失败重掷一次 | 敌人做的检定（越过空隙等）失败时重掷一次 |
| 红皮人 | 热耐性：受火伤 −25%（和克制加算）；附赠扑灭身上所有灼烧 | AI：身上有灼烧时用附赠扑灭 |
| 犬类人·狼 | 独狼：区里没有队友时 atk + 等级÷2；有两名及以上队友时 atk − 等级÷2 | 「队友」= 同阵营的友方单位，召唤的小兵也算（不含配置物）。赤牙带部队出场时 atk 会降，作者确认保留 |
| 猫类人·豹 | 迅袭：每次移动回 1 架势；整场第一个行动时第一击 +1 击破 | |
| 猫类人·虎 | 威压：附赠，对近距一个敌人威吓检定，成功施加不稳 | 敌人的威吓检定 50% 成功；需要 AI |
| 鼠类人·鼠 | 环境适应：区域效果减半 | 敌人版改成：每次受到场地伤害或冻土击破，50% 概率完全免疫（作者 10/21 定） |
| 牛类人·马 | 千里马：短休后的下一场战斗第一回合 +1 附赠 | 敌人：第一回合 +1 附赠 |
| 兽人·狼 | 追猎本能：附赠对一个敌人施加紧追 | |
| 兽人·牛 | 缺陷·易怒蛮牛：血量低于 50% 时受到任何伤害，不受控地冲撞（失去附赠 → 移到另一个区 → 随机目标 1 击破）；每回合最多一次（回合开始重置），晕眩 / 失衡时不发作，一击（含高压场地等连带伤害）里任何一段打出失衡 / 晕眩则整击不发作、不占次数；一击结算完才冲 | |
| 兽人·蜥蜴 | 吐酸：附赠，近距 1×atk 酸，每场一次；缺陷·鳞片：受能量伤害 +25% | |
| 兽人·猫 | 灵巧：一回合最多失去 2 架势；缺陷·注意力涣散：连续超过 1 回合攻击同一目标（不止一个目标可选时）伤害 −25% | |
| 兽人·熊 | 重装操作、嗜睡 | 战斗里不生效，只写在资料里（作者确认可以） |

没有战斗效果的：犬类人·狐、犬类人·犬、猫类人·猫（夜视：黑暗还没做）、鼠类人·兔、牛类人·牛、牛类人·羊、牛类人共有的情绪波动（检定劣势）。

## 5. 显示

- 铭牌悬停、单位说明：写种族和生效的被动，例如「狂徒（锤）· 红皮人」。
- 图鉴：固定种族写种族；随机的写「随机：人类 / 红皮人 / 类人」，遭遇过的记下见过哪些。
- 联机：种族是公开信息，照常下发。

## 6. 跑团主持人

和个体值一样：战斗模板的敌人行、主持人工具「生成敌人」可以指定种族（空着 = 随机）；战斗中可以改。

## 7. 已定的细节（作者 10/21）

- 「独狼」的队友：同阵营的友方单位都算，**召唤出来的小兵也算**。
- 猫类人·虎「威压」：敌人的威吓检定一律 **50%** 成功。
