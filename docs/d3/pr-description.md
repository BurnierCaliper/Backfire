D3 在 D2 本机权威模型上接入在线跑团：主持人开房、玩家各自使用自己的设备；房主执行规则和存档，玩家仅消费脱敏显示数据。基于 `main` 的 D2 合并提交 `04e9ef2`，按 PRD v1.1 第 5 节 D3 与 Q2–Q17 实现。

## 范围与入口清单

- [ ] Cloudflare Workers + SQLite Durable Objects 转发服务，`RelayTransport`，房间码、协议/构建检查、端点身份、重连令牌与消息限额；浏览器游戏不新增运行时依赖。
- [ ] 标题联机开房/加入；主持人选择跑团存档；大厅座位、在线状态和角色分配，角色归属与昵称分离。
- [ ] 房主唯一执行、客户端按序播放结果，跳号请求重同步，客户端不运行规则或伤害预演。
- [ ] 复用单位顺序、武器动态加入/离开、临时互换和本人协助询问；已挪走空位与尚未选择区别显示。
- [ ] 玩家掉线顺位等待 60 秒后跳过，协助视为拒绝；房主掉线全体暂停；房主恢复、玩家令牌重连、探索/战斗/询问重同步。
- [ ] 玩家 DTO 全面过滤结果、状态、演出事件（含 pop.snap）、日志、重同步和私信历史；完整状态仅房主保留。
- [ ] 主持人生成敌人；区分移出/正常击杀；生成敌人从下一次敌方回合行动。
- [ ] 主持人合法修改单位、配置物、间隔、场地、天气、战前遭遇及现有队伍/探索后台；演出期间排队；默认显示安全摘要，可选静默。
- [ ] 主持人可手动操作指定/全部敌人；其余先由 AI 行动，手动操作后结束敌方回合；预测标记手动单位不可预测。
- [ ] 主持人全体/单人消息，玩家回复主持人；其他玩家的包内无私信正文，重连历史按收件人生成。
- [ ] 本地多浏览器真实 WebSocket、手机视口、30 秒断线/恢复、隐私及权限回归；现有测试断言不改。
- [ ] README 记录置顶；部署/配置/免费额度及限制、验收记录均在 docs/d3；`npm test` 与 `npm run test:ui` 通过；大文件不入仓库。

不包含 D4 合作单局决策、房主迁移、账号系统、语音、观战或评分/数值调整。D3 单独评审合并后再开展 D4。

开发中。公网部署与真机验收须有可用的 Cloudflare 部署账号/服务地址；本地浏览器模拟不冒充公网和真机验证。
