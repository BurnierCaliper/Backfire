## 公网服务验收

经作者明确授权，2026-10-04 新建了独立服务 `backfire-relay.richardguu22.workers.dev`，版本 `4d8e54e9-e4b8-427d-aacc-810b417c496b`。既有三个网站服务、域名和路由未修改；新服务没有自定义域名或路由，只有自己的两个 SQLite Durable Object 绑定。沿用已有 Wrangler 凭据，未新增账号权限或变更套餐。

`node tools/test-online-public.cjs` 公网专用套件 **4/4 通过，0 跳过，约 55 秒**。同一台电脑的三个隔离 Chromium 会话连接真实 Cloudflare 服务，包含一个 390px 视口；网页由本机 8080 端口提供，未使用本地 workerd 转发。覆盖真实胜利/保存/返回探索、反应中房主刷新、角色越权拒绝、私信帧隔离、协议与构建不匹配拒绝且不占座、房主断线 30 秒后的原令牌恢复和玩家刷新恢复。四个房间，无压测。

公网截图检查发现玩家界面外层仍可滚到旧面板模板，已限制玩家页面只显示联机与顺序界面。新增真实页面断言验证旧模板隐藏、外层页面不溢出；修复后公网胜利/探索闭环 1/1、本地完整会话 3/3 复测通过，390px 截图已检查。

## 作者验收反馈与界面回归

2026-10-04 作者确认 D3 功能验收通过：私信隔离、隐藏信息、生成敌人、修改天气正常；同时指出主持人工具入口被房间消息按钮覆盖，并要求统一天气名称。

在原样式上运行新增完整页面回归，1440×900 探索界面就能稳定复现两个按钮矩形相交。已将主持人工具放到消息按钮上方，展开面板同步抬高并保留内部滚动。`tests/online-session-ui.test.js` 使用真实 `game.html`、本地转发与三端会话，在探索、战斗及「敌人待操作」长文案三种状态检查 1440×900、768×1024、390×844、320×568、844×390、568×320 六种视口。断言按钮均在视口内且不相交，再用浏览器普通点击分别打开工具面板和消息面板，禁止强制点击或事件注入绕过遮挡。

主持人工具与玩家天气显示统一为「常态 / 酷暑 / 雪天 / 酸雨 / 雷鸣 / 微光 / 沙暴 / 相位」。两处 D3 界面测试覆盖全部八个数据键与显示名称；天气规则和砂甲名称均不变。以上扩充既有 D3 测试用例，不修改 D2 及更早断言，也不增加公网套件房间数。

修正后上述 18 种界面组合全部通过，桌面与 390px 截图已检查；重新执行完整 `npm test` 和 `npm run test:ui`，结果见上表。本次修改仅涉及网页显示与测试，转发服务未改动，未重新部署。

## 待设备验收与限制

- 仍需主持人加两名玩家使用各自设备，其中一台真实手机，完成公网遭遇与返回探索，并复测私信、30 秒断线及恢复。
- Chromium 390px 测试不能代表 Android Chrome、iOS Safari 真机体验。
- 跨设备与移动网络下的结果传递延迟仍待验收，演出时长另计。
- 原面板操作默认发安全摘要；静默勾选在新增主持人工具中。房主恢复会作废未确认的顺序互换，需要重新申请。
- 房主恢复和全部消息历史依赖原浏览器本机存储；存储失败会显示提示。房间有效期为 24 小时，过期可由房主用原跑团存档重开。

上述剩余项目不以同机隔离浏览器测试替代。PR #4 保持草稿，等待实机验收与作者评审；本期不合并，也不开始 D4。
