## 1. 两种玩法

### 1.1 主持人分阵营（联机跑团）
- 主持人可以在战斗中把**玩家角色当作一个单位加入战场**，和「生成敌人」一样。
- 主持人可以把玩家角色**分到不同的阵营**，并且**单独设置每个阵营和其他敌人阵营的敌友关系**。
- 每个阵营定在**我方回合**或**敌人回合**行动：
  - 被放到敌人回合的玩家角色，**已经分配给玩家的**，由那个玩家在敌人回合自己操控；
  - 没有分配给玩家的，由主持人操控。
- **玩家角色总是比同一回合里的敌人（非玩家单位）先动。**
- **行动顺序：所有玩家统一在这一轮开始时选**（作者 10/29，#478）：这一轮开始时（我方回合开始前那一次），**所有玩家角色**——不管在我方回合还是敌人回合行动——**一起排行动顺序**。
  - 在敌人回合行动的那一队，照排好的顺序在敌人回合里行动（仍然在敌人回合、仍然比非玩家单位先动）；敌人回合开始时不再另外排一次。
  - 联机：照现在排顺序的界面，每个玩家给自己的角色排（选格子、确定），一次排完整轮。
  - 只有一个玩家阵营（普通 PvE）时一切照旧。
- **协助攻击的优先**：某个阵营里有玩家角色时，同阵营的任何非玩家单位打出失衡，**先问这个阵营的玩家角色要不要协助攻击**；玩家都不选，才轮到同阵营的非玩家单位协助攻击。

- **加入战场的玩家角色**：主持人可以选**任何一张角色卡**——房间里已经有人在用的、没人用的都可以（作者 10/28）。
- **自己人**：同一个阵营，或者单独设成**友好**的阵营（作者 10/28）：
  - 群体增益、单体给友方的技能都能给友好阵营的人；
  - 友好阵营之间**也能协助格挡**；
  - 高能余波、感电波及**放过友好阵营的人**。
- **友好不传递**：甲—乙友好、乙—丙友好、甲—丙敌对时，丙打甲，**乙不替甲挡**（车也不替挡）——两边都是朋友，就两边都不帮（作者 10/28）。
- **载具**（作者 10/28）：
  - 代挡：有人驾驶的车算驾驶员的阵营；**玩家留下的空车谁都不算、谁都不替挡**；镇压队等敌人留下的空车照旧替那个敌人阵营挡。
  - 上车、拉人下车按阵营：车上有敌对阵营的人不能上；自己人（同阵营或友好）可以一起坐；敌对阵营的人可以拉下车，自己人不能拉。
- **胜负**：战斗进行到**某个阵营的所有敌对阵营单位都倒地或死亡**为止，这个阵营获胜。

### 1.2 决斗（联机，玩家之间）
- **怎么开始**：联机模式多一个「**决斗**」按钮，**只能在探索环节按**。
  - 玩家申请发起决斗，**主持人同意**后开始；或者主持人主动开启。
- **队伍**：只有 **1 队**、**2 队**两队，玩家自由选队；**每队最多 4 人**，两队人数**可以不一样**。
- **先后手**：开局**抛硬币**决定哪一队先手（后手的补偿见第 2 节）。
- **伤害不会致死**：坚毅生命打到 1 时保留 1，那个角色显示「**再起不能**」，然后移出战场。
- **起身**：决斗可以设置**是否允许起身**。不允许起身时，倒地的角色**仍然留在场上**，只是不能自己起身——这样还能被特定专长救起来。
- **一个队伍全部倒地，另一个队伍胜利。**
- **回合上限（可选规则，作者 10/28）**：开决斗时可以打开「限定回合数」。到了限定的回合数还没分出胜负，**哪一队剩余血量百分比更多，哪一队获胜**。
  - 剩余血量百分比 = 这一队所有角色现在的血量合计 ÷ 血量上限合计（只算各层血量，**不算坚毅生命**——坚毅数值不给玩家看；倒地的人现在的血量按 0 算）。
  - **默认 10 回合**；两队百分比一样时算**平局**（作者 10/28 确认）。
- **决斗结束后**：血量、坚毅生命、武器耐久**恢复成决斗前的样子**；**用掉的道具不恢复**。
  - 因为坚毅生命会恢复，「再起不能」透露的坚毅生命剩 1 只在这场决斗里有效，不算违反「坚毅数值不给玩家看」（作者 10/28）。

### 1.3 两种玩法都适用（作者 10/29）
- **单人队伍**：一个队伍（玩家阵营）只有一个玩家角色时（武器人、护送对象不算），他可以**给自己协助格挡和协助攻击**（照单人模式的主角）。
  - 被攻击时自己挡；自己打出失衡时自己接协助攻击。花费、成功率、协助攻击的效果都和平时一样，只是能对自己用。
  - 按当时场上还在的玩家角色算：后来又有人加入（第二个玩家角色）就不再算单人；人倒地 / 移出后只剩一个时又算单人。
  - 只有一个玩家阵营（普通 PvE）时一切照旧；单人模式本来的规则不变。
  - 做法见 README「规则改动记录」#471（`app.js · pvpSoloHero`）。
- **全员倒地但还能起身**（通用规则，所有模式）：队伍里所有人都倒地、但还有人能起身时不立刻判负；回合结束前问每个能起身的角色要不要起身，至少一人起身就继续。PvP 里按每个阵营分别看。
- **起身翻滚**（通用规则，所有模式）：起身时可以选择免费翻滚到一个相邻区域，翻滚过程不触发任何反应、无视酸液地面和冻土这类场地效果。

## 2. 先后手与补偿
- 先手、后手按回合分：我方回合行动的一方是先手，敌人回合行动的一方是后手。现在的程序开战总是先进我方回合（`app.js · startCombat`）。
- **后手开局补偿 1 个附赠动作，开局就有**：开战时后手方每个角色手上先有 1 个附赠，**在先手的第一回合里就能用**（主要拿来协助格挡：格挡成功时目标最少保留 1 架势，挡下的那一下打不出失衡）。
- **两队人数不一样时（例：4 对 2）不另外补偿**，只有这一条先后手补偿：人多打人少本来就占优势，这就是现实（作者 10/28）。
- **没用掉的补偿留着**：轮到后手自己的回合时，这个附赠叠在当回合的附赠上（例：第一回合有 2 个附赠），**直到用掉之前一直保存着**；那一回合晕眩不能行动时先收着，下一个能行动的回合照样叠上（作者 10/29）。
  - 注意：现在的程序在自己回合开始时会把附赠直接重算覆盖（`app.js` 回合开始补行动点那一段），做的时候要专门让这一个留下来。

### 2.1 每回合 / 本回合的效果跟着各队自己的回合（作者 10/29，#476 / #482）
在敌人回合行动的玩家阵营（后手）自己的回合是敌人回合。**每回合开始 / 本回合的效果、护盾回满只有这样的阵营受影响，普通 PvE（没有这样的阵营）照旧；即时效果普通 PvE 也改（作者 10/29 追加）。**
- **每回合开始 / 下回合开始的效果**：改到这个角色那一队自己的回合开始（敌人回合开始、补行动点之前），整轮开始（我方回合之前）不再结算它们——夏的燃油和自动碾压、夕夏引擎「一回合没攻击就熄火」（从自己上一个回合开始算起）、结人的咖啡豆和双重奏的 atk、绯秋「粉落汤气」、扭矩「转移注意」和酸液炮蓄力、Ecmo 探测模式、诺拉的翻面 / 压力升高 / 刺入超距、托乌的圣盾、自我效果（焚身、霜结、再次霜结的免疫、蓄能、溅射的酸雨回复）、专长的 `roundStart` 钩子。
- **「本回合内」的效果**：持续到**施放者那一队下一个回合开始之前**。我方放的本来就是撑过敌人回合、到下一轮开始才没，所以和以前完全一样；在敌人回合行动的那一队放的，要撑过对手（我方）的下一个回合——咬牙坚持、屹立不倒 / 还魂、防守反击、全反击、掩护 / 挺身、坚挺、振奋、看天 / 保释、破釜沉舟的双倍攻击、铁壁、锁定、驻波墙、算法改变；对敌人用的禁足怒吼、撼动的禁足、恐惧怒吼的虚弱、加倍计量、恶劣环境、击破预告（判定也在施放者那一队下一个回合开始之前）。结人「思念+」按被牵挂的那位队友那一队的回合判「这一回合没受伤」；绯秋「剑术+」按她自己那一队的回合算；瑞比的无人机 / 机甲在她自己那一队的回合结束。
- **即时效果**（刺骨、熔融、扩散、折射、错位、过载、熔融护盾）：从施加起一定要经过一个我方回合和一个敌人回合（含施加时所在的那个）才失效——**施加时是谁的回合，就持续到那一方下一个回合开始之前**，不看是谁施加的（作者 10/29，#482）：我方回合里施加的到下一个我方回合开始之前（下一轮开始）；敌人回合里施加的撑过下一个我方回合，到下一个敌人回合开始之前才失效。在自己的回合里施加的和 #476 一样；变的是在对手的回合里用反应（协助攻击、借机攻击）施加的——#476 按施加者那一队算，只经过一个回合就失效。例：在敌人回合行动的阵营在我方回合里协助攻击施加的刺骨，撑过紧接着的敌人回合，到下一个我方回合开始之前才失效。**普通 PvE 也照这个**（作者 10/29 追加），例：敌人在敌人回合打在我方身上的刺骨 / 熔融，以前到下一轮开始就没了（只经过敌人回合），现在撑过下一个我方回合；敌人在我方回合里用反应施加的（警棍盾的协助攻击带的熔融）撑过紧接着的敌人回合，到下一轮开始。黄金时间的「多保留一回合」照样在这个基础上再延长一回合。沙灵聚合体开炮后的自身熔融也照这个（#482）：在敌人回合开炮，正好持续到下一个我方回合结束。中和打掉的护盾跟着在敌人回合行动的那一队（普通 PvE 里只有我方用中和，照旧）。
- **护盾层「这一回合没挨打就回满」**：在敌人回合行动的阵营，在自己那一队的回合开始时判「从自己上一个回合开始到现在没挨打」就回满。
- **不改的**：持续伤害（灼烧、感电、腐蚀、冻伤）、场地（酸液、能量场、治疗场、流沙、火场、干涉）、天气（沙暴风向）照旧整轮统一结算。
- **待作者确认**（#476 的 PR 里列了；在对手的回合里施加的即时效果、沙灵聚合体开炮后的自身熔融 #482 已经定了，见上面）：高压巡逻艇给自己的过载（整轮开始给的，照「施加时是谁的回合」算我方回合，到下一轮开始，和现在一样）；沙尘层每回合恢复；年糕「咬住」的时长。

## 3. 开局站位
- **采用 3 区制，两边开局隔开**（像格斗游戏那样两边各站一头）：一边在 1 区、一边在 3 区。
- 近战第一回合打不到人；远程照常能打。

## 4. 计分
- PvP 里**每个队伍（阵营）单独计分**：各自打对面的伤害、击破、击杀照常记进自己队伍的分数。
- **只算原本的分数，不看额外加成**（作者 10/28）：速杀奖励、无伤奖励、遭遇战加成、克制大师、「克制 / 大伤害加成」这些额外加成都不算；伤害、治疗 / 护盾、击破、打出失衡、协助格挡、减伤、格挡减免、击杀、行动这些原本的分数照算（`app.js · SCORE_PART_NAMES`）。
- **打进坚毅生命的伤害也照算**（那一下的减伤、格挡减免也算；分数里只有分值，没有坚毅数值。作者 10/29）。
- **分数只是显示**：不给奖励，也不记进战场数据、最近 10 场表现。战斗结束后，**两队的分数数据展示给所有玩家看**。

## 5. 嘲讽对玩家（作者 10/28；10/29 调整）
- 玩家角色被嘲讽时，**也只能选嘲讽它的那个单位作为攻击目标**（和敌人被嘲讽一样）。
- **被嘲讽了就只能打嘲讽的**（作者 10/29，#478）：被嘲讽时**所有攻击**都只能以嘲讽者为目标，**开着友伤也不能去打队友**。
  - 只限制**攻击**：给友方的治疗、增益这类不是攻击的技能不受影响。
  - 协助攻击、协助格挡、借机攻击这类**反应**不受嘲讽限制、也不用掉嘲讽（作者确认 #467 的做法）。
- 玩家角色被嘲讽时，**它的武器人一起被嘲讽**，同样只能打嘲讽者；武器人和持有者共用一次嘲讽（谁先打了嘲讽者，两个都解除）。

## 6. 沿用的规则
- 打对面的角色和打敌人完全一样结算（克制、减伤、格挡 / 协助格挡、失衡、被动……）。
- 坚毅生命的数值照旧绝不给玩家看（联机发给玩家的数据都要过 `online-view.js` 的白名单）。
- 友伤开关照常可用（同队之间）。

## 8. 争斗（联机新玩法，#543，主人 11/01 确认）
和「跑团」「联机单局」并列的一个联机玩法：单独开一局的 PvP，固定等级段，开局选好人数、角色和每个角色的养成，翻硬币开打。
**第 1 步（规则和布置，brawl.js）已经做完**；**第 2 步（接联机，issue #560）已经做完**：「玩法」多一项「争斗」、房间里选人数 / 角色 / 养成（online-brawl.js、brawl-ui.js）、翻硬币动画、行动顺序沿用联机的会话排顺序（hotseat.js）、AI 整队由房主替它出手、发给玩家的照旧走 online-view.js 的白名单，见 8.4 节。第 3 步：打 AI 的体验和结算画面。做法见 README「规则改动记录」#543、#560。

### 8.1 规则
- **对手**：可以打真人，也可以打 AI。**AI 只能整队**：一队要么全是真人，要么全是 AI，不混编。AI 用 `BattleSim.SKILL_POLICY`。
- **等级段**（二选一，`BRAWL_CFG.tiers`）：**Lv20、武器 10 级** / **Lv10、武器 5 级**。武器等级是这个角色所有武器都设成这一级。
- **人数**：1v1 ~ 4v4，**两队人数一致**。
- **选角色**：**同一队里不能重复，两队之间可以重复**（例：1 队、2 队都用夕夏）。
- **每个角色的养成**（选完人数、角色之后逐个选）：
  - **专长**：照这个等级段应得的项数（`ROGUE_LEVEL_REWARDS` 里 `key: "feat"` 的那几级：Lv10 是 7 级一项，Lv20 是 7 / 11 / 13 / 16 级四项），每一项自己选，合法性照单局 / 跑团升级时的规则（`featChoicesFor`）。探索专长只在跑团规则下提供，争斗不提供；拿了兼修要再选一张升成完整版。
  - **属性加点**：照应得的点数（4 / 8 / 19 级），8 级那一点不能加在之前加过的同一项上。
  - **血量层改造**：照诊所的规则（`cyberPlanError` / `cyberLayersFor` / `CYBER_RATIO`），可换的肉体上限照改造率上限算（按选完属性以后的智力、等级），可以把肉体全换成星灵。**不收钱**。
  - **职责路线**：不用选，职责绑定角色，照角色自己的那一条给。
  - **熟练项**：不选、不给（角色卡自带的照旧）。
  - **不带**：义体、改装件 / 图纸、道具。
  - 不合法就拒绝并写原因，不悄悄改成合法的。
- **开打**：全部选完 → **翻硬币**定先手（写进战斗记录）→ 进入战斗。
- **对战规则照决斗**（第 1.2、2–6 节）：不致死（再起不能）、后手开局补偿、3 区制两头站、每队单独计分；允许起身、回合上限（打开时默认 10 回合）在开局选人数时一起设。
- **和存档无关**：不读也不写玩家的跑团角色、单局存档；打完不给经验、奎支、掉落，不记战场数据。开局把队伍档案、背包、奎支收起来换成空的，打完原样放回去。
- **行动顺序**沿用联机现在那一套（hotseat.js 的会话排顺序），第 2 步接联机时直接用。

### 8.2 两队同一个角色
规则里很多地方按 kit 找「那个角色」。争斗里同一个 kit 可以有两个：找的时候先看「现在是谁的事」（正在行动 / 格挡 / 协助攻击 / 起身 / 出手打人 / 结算回合效果的那个单位，或者调用的地方指明的那个人），挑他自己、他的武器人 / 持有者、同一队的那一个；武器人记着持有者是谁（按单位 id）；武器耐久、长休次数这些按 kit 记的两个人分开记；开战、每回合「这个角色」的效果每个人都结算。伤害、协助格挡、倒地 / 再起不能都落在对的人身上。

### 8.3 熟练项会影响的战斗检定（争斗不给升级得的熟练项）
- 离开冻土：简单「运动」检定（结人「冷萃」能造出冻土）。角色卡自带的运动熟练照算。
- 越过空隙（运动）、改写炮台（数据操作）、载具的检定：争斗的战场没有间隔、配置物、载具，碰不到。

### 8.4 联机（第 2 步，issue #560）
- **开房**：联机开房的「玩法」选「争斗」，和跑团 / 联机单局一样走房间、转发服务、断线重连。大厅是争斗的房间画面（房主、玩家共用）。
- **房主定设定**（房间里的人都看得到）：等级段、每队人数、允许起身、限定回合数（打开时默认 10 回合）、哪一队交给 AI。改了设定大家要重新按「准备好」。
- **选位置和角色**：玩家自己选进 1 队或 2 队的空位、选角色；同一队里不能重复，两队之间可以；一个人只在一队，可以拿几个位置。交给 AI 的那一队整队是 AI（随机补上角色，房主可以换），真人选不进去；一个人开房对整队 AI 也能打。
- **养成**：每个角色一项一项选属性加点、专长、血量层改造（菜单 `brawlChoices` 和校验 `brawlBuild` 同一套规则）；都选好按「准备好」，不合法写清楚原因。**开打之前互相看不到对方的养成**（只看得到对方选了哪个角色、选好没有）；开打以后血量层自然就看得到了。
- **开打**：所有位置都有人或 AI、真人都准备好，房主点「开打」→ 翻硬币动画（谁先手、后手的补偿）→ 开战。
- **行动顺序**：照会话（hotseat.js）：每一轮开始两队一起排，没动过的单位随时可以换位置。
- **AI 整队**：会话里的一个操作者，轮到它时由房主替它排顺序、出手（`brawlPolicy` 的那一套），一步一步来，节奏和联机里敌人 AI 的出手一样；协助格挡 / 协助攻击也替它答。AI 的想法不发给玩家。
- **结束**：照决斗结算（谁赢、两队分数），不给经验 / 奎支 / 掉落；房主点「回到房间」再来一局（设定、位置、养成都留着，「准备好」要重新按）。
