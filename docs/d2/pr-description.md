## 范围与入口

- [ ] `?hotseat=1` 开发入口，2–4 名操作员，本机切换当前操作员；普通单机不出现热座界面。
- [ ] 跑团主持人分配角色，未分配角色由主持人代操作；一操作者多单位。合作配置每人一角色。武器人跟随主人，伙伴/无归属召唤物不可直接操作。
- [ ] LocalTransport 绑定发送者身份；JSON 指令→房主校验→唯一规则执行→结果/顺序/询问消息。协议及构建版本不一致拒绝，重复消息不重复结算。
- [ ] 回合开始效果结算后选顺序，角色和已上场武器人各一格；先到占格、本人全部单位确认、主持人按当前格子自动补位开始。
- [ ] 当前顺位且归属正确才能使用技能（含分步）、移动、起身、道具；结束本人顺位后交给下一单位，全部结束才进入既有敌人回合。
- [ ] 临时移动空位立即生效，同操作者单位互换、跨操作者互换请求/同意，跑团主持人可直接调整；目标只能在固定格之后。
- [ ] 实际行动点/附赠行动支出、已完成格子锁定；预览/取消不锁，扣点后退款仍算支出，反应花费同样锁定。
- [ ] 武器人中途上场追加、收回/击败移除；同回合重唤不清除已支出/完成记录。倒地仍可起身的角色保留顺位，不可恢复/永久死亡者旁观。
- [ ] 协助格挡/攻击只向符合条件者的操作者发选项；其他人等待。20 秒超时、全部拒绝、先到同意关闭其他询问；额外选刀由本人选择。
- [ ] 选序画面的文字协商，本机消息有界；未引入主持人公开/私密消息功能。
- [ ] 热座不建立撤销快照，按钮与快捷键不可用；旧单机撤销保持原样。
