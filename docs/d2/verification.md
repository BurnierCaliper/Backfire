## 最终命令

使用本机已有 Playwright/Chromium，通过 `NODE_PATH` 指向现有运行库，并设置 `REQUIRE_UI=1`：

```powershell
npm test
npm run test:ui
git diff --check
```

| 命令 | 结果 |
|---|---|
| `npm test` | 450 项：449 通过，0 失败，1 项原有跳过；实际执行全部浏览器测试 |
| `npm run test:ui` | 54/54 通过，0 跳过 |
| `git diff --check` / `git diff --cached --check` | 通过 |

唯一跳过项是原有 `ROLE_PATH_CHOICE` 关闭时的职责技能分支，不是 D2 或浏览器缺失。D1 基线共 368 项，本期新增 82 项测试，其中 16 项为真实浏览器测试。2/3/4 人均完成实际战斗，包含中途唤出武器人、至少一个敌人回合、下一回合重选、真实技能击杀和唯一奖励结算；另验证非主持人最后一击后跑团结算存档并返回探索。

390px 三人选序与战斗画面已检查；桌面拖动、触屏按钮、选序期互换、协助选项隔离与手机布局均有回归。现有测试文件未修改。新文件最大 31,851 字节；未新增图片、压缩包或运行日志。
