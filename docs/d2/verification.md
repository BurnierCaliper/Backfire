## 覆盖范围

| 层 | 回归内容 |
|---|---|
| 单位顺序 | 2/3/4 人、主持人多角色、未分配归属、武器继承、选格冲突/确认/补位、可起身与失能、固定格与空位、跨主人互换同意、重召保留锁定 |
| 权威和传输 | 绑定发送者、协议/构建不匹配、JSON 拒绝、重复编号、唯一结算、收件人副本、错误后的权威广播、关闭连接、回调重入 |
| 真实规则 | 实际扣点观察、同指令退款、免费/付费格挡、免费起身、道具、飞行附加消耗、分步与目标/射程校验，拒绝不改状态引用或消耗随机数 |
| 桥接 | 越权/越序、旧 calc 动作及嵌套编辑入口不能绕过、逐单位结束、预览隔离、跨回合开场反应锁定、本人选择、最后单位离场衔接敌方 |
| 真实浏览器 | 热座配置、选序与交换、完整战斗、反应投影、回合轮转与结算；390px 触控按钮与桌面拖动；普通单机入口与撤销 |

仅新增测试文件，保留现有测试断言。完整测试必须使用实际浏览器执行，不能以缺少 Playwright 的跳过作为 UI 验收通过。

## 最终命令

使用本机已有 Playwright/Chromium，通过 `NODE_PATH` 指向现有运行库，并设置 `REQUIRE_UI=1`：

```powershell
npm test
npm run test:ui
git diff --check
```

最终运行结果在完成后填入此处。

## 界限

本期测试的是同页 LocalTransport；没有把多标签网络联机、移动端真机或重连当作已通过项目。390px 验证使用 Chromium 移动视口；D3/D4 继续承担网络与真机验收。图片、浏览器轨迹和运行日志留在系统临时目录，未纳入仓库。评分、数值表和存档序列化格式未改。
