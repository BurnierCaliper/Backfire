# 新敌人批量平衡模拟（外城区镇压部队 · 移动堡垒 · 敌人种族被动）

只测量，不改任何数值。下面的表由 `tools/enemy-balance.js` 生成，重跑会覆盖到「手写分析」标记为止，标记之后的手写内容保留。

- 版本：提交 `087f4ed5aa4f42b684b3bccb231ff1ab92b9fe64`；规则源码 SHA256 `5b2c2f7cea557991…`；Node v22.23.3；工具 enemy-balance-v1
- 命令：`node tools/enemy-balance.js --samples 100 --workers 1`
- 样本：每格（一种人数 × 一个对照组）**100 场**，人数 2 / 3 / 4；共 11700 场，异常 0 场，超时 34 场（超时算进分母，不算胜）。
- 种子：`EB1021:组:格:人数:序号`（序号 000–099）。同一格的对照组共用种子：队伍、等级、区制、站位、天气、配置物完全一样，只差要比的那一处。
- 布置：照 R1 单场矩阵（`tools/score-by-act.js · one`）——R1 的 10 名角色里按种子随机 2–4 人；外城区 = **第 1 幕**，敌人等级按这一幕的任务天数取、精英战 +1、首领 = 本幕上限（每格的范围见「敌人等级」一列）；我方等级 = 敌人等级，升级选主属性 / 第一个合法选项，武器等级 = 等级 × 0.6（最高 10）；满状态、不用道具；我方 BASIC 打法（打得到就普攻血最少的，打不到就走一格），敌人用游戏里的 AI；30 回合上限。
- 遭遇：走单局的 `battleSpec`（个体值 ±10% 打开、随机种族照抽、任务天气 / 战场配置物照抽），只在「抽遭遇」那一步换成要测的敌人。
- 胜率是 BASIC 自动打法的胜率，**不是真人胜率**；看的是两组之间的差。区间是 Wilson 95%。

列的意思：「我方承伤」= 一场里我方所有单位受到的伤害合计（含坚毅生命、持续伤害）；「倒地」= 一场里我方角色倒地次数；「灼烧人·回合」= 每回合敌人行动完时我方在场角色身上挂着灼烧的比例。
兵种伤害写成「直接伤害 + 持续伤害（灼烧等，记在挂状态的人名下）/ 击破 / 倒（打倒地的次数）」，都是每场平均、只算打在我方身上的。

### C. 种族被动

- 开 / 关的胜率差都在 3 个百分点以内：盗匪遭遇 ±0.0、狼队长 ±0.0、牛队长 −2.7、蜥蜴队长 −0.7、亡命之王 +1.0。**种族被动整体对难度影响很小。**
- **「易怒蛮牛」对敌人不是缺陷，反而略强**：牛队长开着被动时我方承伤 138 ↔ 123（3 / 4 人队都多 15–25），它打出的伤害 136 ↔ 121、击破 28 ↔ 24.5；胜率差 −2.7 在误差内，但方向一致。失控冲撞每次白给随机一人 1 击破。设计文档说它「会让盾墙自己散掉，是给玩家的解法之一」——在这个打法下看不出来是解法。警棍盾也是兽人·牛，B2 的差距里可能有一部分来自这里。
- 「追猎本能」（狼）开 / 关几乎没差：胜负数完全一样（237 / 63），伤害、击破差不到 2%。AI 只在不用移动时才用附赠，BASIC 又很少走开，紧追没什么机会生效。
- 「吐酸 / 鳞片」（蜥蜴）：开着时我方承伤 50 ↔ 41（吐酸），胜率贴着天花板，看不出差别。
- **亡命之王各种族**：合计胜率在 12.0%（猫类人·虎）到 15.0%（鼠类人·鼠）之间，人类 14.7%，都在 ±3 个百分点内，没有哪个种族突出——和作者 10/21「全部放进随机不会伤害游戏体验」的判断一致。最低的猫类人·虎（威压）在 2 人队是 1% ↔ 人类 5%。人类、犬类人·狐 / 犬、猫类人·猫、鼠类人·兔 的胜负数完全一样（都是 44 胜 / 256 败），承伤、伤害只差零点几：这几个种族的被动没有战斗效果，体质 ±1 只让王的肉体 ±5（而且同区还有狂徒时，打王的单体攻击由狂徒承受）。
- 顺带看到（不是这次要测的）：**亡命之王首领战本身很难**——第 1 幕 4 级，2 / 3 / 4 人胜率 0 / 10 / 21%（被动开）；R1 同一格是 0 / 21 / 79%（旧版本、不同种子）。种族被动和王的种族都解释不了这么大的落差（见上），可能来自 R1 之后加的东西（援军、随机种族的六维、公开处刑……），建议另开 issue 看。

### D. 规则 / 实现上看到的事（不是调数值，但影响怎么读这份报告）

1. **赤牙部队天气的「灼烧加倍」已经实装，就是酷暑的效果**（作者 10/21 确认；报告初稿把它当成另一条没实装的规则，写错了）：酷暑下灼烧每回合结算后叠 2 层（平时 1 层），另外火 +25%（`app.js` 回合结束的灼烧结算）。图鉴写的「酷暑 + 灼烧层数加倍」说的是同一件事。第 4 组测的就是完整的部队天气：胜率 −7.3（61.0% ↔ 68.3%），承伤 +16%，没到 10 个百分点。
2. **「抢车」这条解法没测到。** BASIC 打法只会普攻和走位，不会上车、不会拉人，所以「抢车 / 场」一定是 0。R1 名单里有「运动」熟练的是 tou、xia、kolt、ras（拉人是困难检定，一级熟练 25%），有「载具驾驶」的只有 yuito（上车是普通检定，一级熟练 50%）。想知道抢车值不值得，需要另写一个会抢车的打法再测一轮。
3. **敌人挂在我方身上的灼烧不知道是谁挂的。** 规则只给「我方挂在敌人身上」的状态记了来源（`app.js · statusOwnerId`），所以灼烧、火场的持续伤害只能整体记成「持续伤害 / 场地（不分来源）」，拆不到具体兵种头上。只影响统计，不影响规则。
4. **「ATK 低 1」以外还有别的差别**（都照设计文档写的，不是 bug，但比模板时要一起看）：
   - 警棍盾的伤害骰是 1d4，狂徒（锤）是 1d6：每击平均再少 1；
   - 镇压小队长 1d6、远近皆可，狼队长 1d4、只能近战；
   - 火焰喷射兵没有伤害骰（3 段 × 0.3 atk = 0.9 atk），牛队长是 (1 + ⌊等级/5⌋)d4、远近皆可、2 击破、会自动协助格挡；
   - 血量层换了：模板是单层肉体（狂徒）/ 单层装甲（机器人看守），镇压队是「护盾 + 肉体」。我方打护盾时电 +50%、物理 / 酸 −25%，打装甲时酸 +50%、其他多数 −25%，同样的总血量，队伍的属性组成不同，打起来难度也不同；
   - 火打我方：肉体 +50%、护盾 ±0、装甲 −25%（物理打护盾、装甲都是 −25%）。「火打肉体 +50%」只有打到肉体时才吃得到。
5. **BASIC 打法不躲预警。** 燃烧瓶标定之后有一回合可以离开那个区，喷火兵失衡前也可以先走开躲燃料罐，但 BASIC 不看预警，所以燃烧瓶投手、喷火兵在这份报告里偏强；真人会比这里好打。

### E. 这份报告能说明什么、不能说明什么

- 胜率是固定自动打法（BASIC，和 R1 单场矩阵同一套）在满状态、预设等级下的胜率，不是真人胜率；拿来比「两组之间差多少」比看绝对值可靠。
- 每格 100 场，Wilson 95% 区间大约 ±5–10 个百分点；两组用同一批种子（配对），差值本身的波动比两个区间看起来的小，但 10 个百分点以内的差最好当成「差不多」。
- 等级只取了外城区出现的幕：第 1 幕（普通战 2–4 级、精英战 3–5 级、首领 4 级，见各表「敌人等级」）全部五组；额外第 5 幕（17–21 级）只补了兵种对照和堡垒两组，见 [new-enemies-1021-act5.md](new-enemies-1021-act5.md)。
