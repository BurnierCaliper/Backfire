# 下水道 · 狂鼠（设计定稿，2026-10-22）

下水道是巨人城的一部分，在游戏里是**隶属于巨人城的新区域「下水道」**，没有固定首领。
狂鼠是鼠类人接触实验废料后变异形成的阵营，只出没在下水道。种族规则见 [enemy-race.md](enemy-race.md)。

## 1. 共同设定

- **阵营**：新阵营「狂鼠」，**和所有阵营敌对**（安保、警卫队、镇压队、盗匪……都是），不和任何阵营混编。
- **代币**：杂兵 1 枚，精英 2 枚（和其他阵营一样）。
- **血量全部是纯肉体**：模板原来有护盾层的，护盾 + 肉体合成一层肉体，总量不变。
- **种族：全员固定是「鼠类人·鼠」**，套种族被动「环境适应」（场地伤害、冻土击破 50% 概率免疫），**并且套六维修正**（作者 10/22 特意定的，和其他固定种族的敌人不同）：
  - 体质 −1：最内层肉体 1 级 −2，之后每级再 −1，即 −(1 + 等级)，不随队伍人数缩放（和随机种族的换算一样，`enemies.js · raceDelta`）。
  - 耐力 −1：架势向上取整后不变。敏捷 / 智力对敌人没有作用。
- 数值写法：1 级数值 + 每级增量；架势照模板的写法（`milestone`）。

## 2. 通用机制

### 2.1 狂暴（自我效果）

狂鼠的核心机制。在各兵种写明的条件下进入狂暴，玩家要靠把它们打进失衡来解除。

- **效果**：
  - ATK + 等级（例：10 级撕咬者 14 → 24）；
  - 造成的击破 +1（每一次攻击 / 每一段命中照常算，各 +1）；
  - 受到的所有伤害 −25%（和其他百分比加算）；
  - **每回合可以免费移动一次**（不花附赠 / 行动点）；
  - **架势上限 −2**，可以和其他减少架势上限的效果叠加（让玩家更容易把它打进失衡）。
- **解除**：照程序里现有自我效果的解除方式（`effects.js · endSelfOnStun`）：**晕眩后解除**。10 级起的精英要攒满晕眩标记、真正晕眩才解除（和其他自我效果一样）。中和这类清除自我效果的手段照常能清掉。
- **失衡 / 晕眩中的狂鼠不能进入狂暴**（任何来源都不行）；恢复以后可以再次狂暴。
- 狂暴时 AI 改变行动逻辑，各兵种见第 3 节。

### 2.2 阵营共用被动：狂潮

**敌人回合开始时**，如果**存活的狂鼠里狂暴的数量 ≥ 存活数量的一半**，所有狂鼠都进入狂暴（失衡 / 晕眩中的除外）。

### 2.3 出血（新的通用攻击效果）

- 攻击**打中肉体或星灵层、并对它造成伤害**时触发：对**同一层**额外造成**该层上限 10%** 的**真实伤害**。
  - 真实伤害：不吃克制、减伤、护盾等任何修正；坚毅生命照常规则处理（和其他伤害一样）。
  - 只打那一层，打空了也不溢出到下一层。向下取整，最少 1 点。
- **同一次攻击多次触发时，每次减半**：10% → 5% → 2.5% ……（多段攻击的第 2 段起）。
- 做成通用效果（攻击规格上的一个开关），以后角色 / 其他敌人也能用。

### 潜藏者（杂兵 1）
- **数值**：狂徒（匕首）模板（肉体 17 + 4×(等级−1)、架势 3 每 10 级 +1）+ 鼠类人修正；**ATK = 狂徒（匕首）的 75%，四舍五入**。
- **开战时处于躲藏状态**。近战，主动接近。
- **普通攻击**：近距 1×atk + 1d6 物理，1 击破，施加腐蚀。
- **AI（作者 10/22）**：**疫病暴徒在场时**，优先攻击**还没有腐蚀**的敌人，尽量把所有人都打进腐蚀（配合暴徒的扩散和「所有敌人都腐蚀时狂暴」）。
- **受近战攻击后逃跑**：每次被近战攻击（命中后）都免费往远离攻击者的方向移动 1 个区，不触发借机攻击；被打死、被打进失衡时不跑。
- **协助**：和普通攻击一样，**并且进入狂暴**。
- **狂暴时**：每回合结束进入躲藏。

### 撕咬者（杂兵 1）
- **数值**：血量同潜藏者；**ATK = 狂徒（匕首）**（5 + (等级−1)）。
- 近战，主动接近。
- **普通攻击**：近距 1×atk + 1d6 物理，1 击破，**带出血**。
- **协助**：和普通攻击一样，**并且进入狂暴**。
- **狂暴时**：普通攻击变成**两次 0.5×atk 物理，每一击都带出血**（第二次出血按减半算）。

### 疫病暴徒（精英 2）
- **数值**：警卫队队长（牛）模板，护盾 + 肉体合成纯肉体，套鼠类人修正，**架势 −1**：肉体 = 42 + 12×(等级−1) + 4×⌊等级/5⌋ − (1 + 等级)；架势 4 + ⌊等级/5⌋；ATK 6 + 2×⌊等级/5⌋。骰子固定 1d8（不随等级加骰，靠腐蚀打伤害）。
- **移动**：主动接近**血量最低**的敌人。远近皆可（射程照牛队长）。
- **AI（作者 10/22）**：场上**有敌人已经腐蚀**时，主动用**远程「感染喷洒」打有腐蚀的敌人**，把腐蚀扩散到那一区（优先挑同区还有没腐蚀的敌人最多的那个目标）；没有腐蚀的敌人时，照常接近血量最低的敌人打。
- **近战普通攻击「感染撕扯」**：1×atk + 1d8 物理，1 击破，施加腐蚀。**目标原本已经腐蚀时**，自身恢复 10% 最大生命。
- **远程普通攻击「感染喷洒」**：1×atk + 1d8 酸液，1 击破，施加腐蚀。**目标原本已经腐蚀时**，把腐蚀扩散到目标同区的所有敌人。
- **协助**：近战，移动到目标所在区，1.5×atk 酸液，施加腐蚀；**目标原本已经腐蚀时**，伤害额外 +2d8，自身恢复 25% 最大生命。
- **特点**：**所有敌人都处于腐蚀时进入狂暴**。狂暴时受到的治疗 +50%。

### 暴虐猎手（精英 2）
- **数值**：警卫队队长（狼）模板，护盾 + 肉体合成纯肉体，套鼠类人修正，**架势 −1**：肉体 = 35 + 11×(等级−1) − (1 + 等级)；架势 3 + ⌊等级/5⌋；ATK 8 + ⌊等级/2⌋ + 2×⌊等级/5⌋。骰子 1d8。
- **移动**：主动接近**血量最多**的敌人。
- **普通攻击**：1×atk + 1d8 物理，1 击破，**带出血**。
- **协助（优先权）**：在场时，如果**其他狂鼠都没有狂暴**、且它自己能协助，**一定由它来协助**。协助是 3 次 0.5×atk 物理，每一击都带出血（第 2、3 次出血减半），**让所有狂鼠进入狂暴**。
- **斩杀**：每当一个敌人因为**任何原因**血量降到「它的普通攻击**掷最小值也一定能打死**」的程度（按伤害预演、骰子取 1 计算，克制和减伤照算；打到濒死就算杀死，和游戏里其他地方一样），猎手**免费**移动到那个敌人所在区并**免费**发动一次普通攻击。
  - 每轮没有次数限制；但这一击**可以被格挡，而且格挡概率 +5%**。
- **击杀敌人后进入狂暴**。狂暴时，自己造成的出血伤害等量为自己恢复生命。
