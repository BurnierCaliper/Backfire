D1 将三种单机模式的既有状态变更改为可序列化指令，保留规则执行与视图生成的边界。以 `main` 为基线，同步作者分支的联机 PRD v1.1；一操作者可对应多个单位，武器人按独立单位为 D2 预留接口。

本清单在实现前根据 `game.js`、`rogue-ui.js`、`screens.js`、`trpg-ui.js` 和 `app.js` 的事件绑定及隐式写入盘点，先提交草稿 PR，再逐项实现/验收。纯展示、鼠标悬停和未提交表单不属于权威规则变更；最终表单值必须进入 JSON 指令，不能把 DOM、函数或点击回放当作指令。

## 入口清单（开工前冻结，完成后逐项勾选）

### 指令基础与边界

- [ ] `dispatch(cmd)`、显式类型/动作表、JSON 验证、未知指令拒绝和本地执行结果/错误日志。
- [ ] 权威执行与视图投影分离；完整状态只供权威规则使用，D1 不实施网络发送或脱敏。
- [ ] 单位粒度的归属接口：一操作者多角色/武器人、武器人通过 `weaponOf` 归属、动态在场名单；预留 `orderMove` / `orderSwapAccept`，D2 前不执行顺序逻辑。
