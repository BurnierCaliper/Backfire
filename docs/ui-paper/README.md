# 联机战斗画面 · 纸片风界面（设计定稿）

主人 10/22 定稿。这份是联机玩家的战斗画面（开着新画面时）的排版和美术规格，实现照这里做。

- `mock.html`：可以直接用浏览器打开的样稿，网址加 `?s=day` / `?s=night` / `?s=collapsed` 看三种状态。纸的褶皱、撕边、胶带、收据、便利贴都是里面的 JS 程序画的（`crumple` / `rough` / `zig` / `grit`），正式实现照这个思路做，不放图片文件（双击打开 game.html 也要能用）。
- `shot-day.jpg` / `shot-night.jpg` / `shot-collapsed.jpg`：纸片风样稿的截图（定稿的样子）。
- `layout-open.jpg` / `layout-collapsed.jpg`：排版方案（上一版平面的样子，带编号标注），说明每块放在哪里。
- `bg-day.jpg` / `bg-night.jpg`：样稿用的战场背景（原型页截的）。

## 主人的要求（原话摘要）

- 画面主体就是战场，战场内容占绝大部分；功能性的界面能收起来，不收起来时单独浮在战场画面之上。
- 战场日志和玩家消息平时藏在右边，拉出来时白天是白色（浅色）的，游戏夜晚是黑色的，并且依旧按照天气改色调。
- 队伍名单和单局原型一样放到左上角。
- 最终画面更简洁、整体更自洽。
- 美术：有褶皱的纸的风格，不要太规整（选的是「矿场作业单据」打底 + 一点「涂鸦纸箱」）。
- 聊天内容以识别度为先，确保没有误读（聊天正文用清楚的无衬线黑体，只有发送人名字用手写感的字体）。

## 排版（1440×900 为例；手机竖屏见最后）

| 位置 | 是什么 | 收起后 |
|---|---|---|
| 顶上一条 | 美纹纸胶带：联机跑团 · 房间码（红色橡皮章）· 第 N 回合 · 时间 · 天气；右边镜头 远/中/近、「工具 ▾」（纸板）、「菜单 Esc」（黄纸） | 不收起 |
| 顶栏下面中间 | 行动顺序：一串用细线挂在胶带下的牛皮纸吊牌（职责头像 + 名字 + 操作者），当前行动的是青色；自己的角色带 ⇅（延后 / 换位） | 不收起 |
| 左上角 | 队伍：回形针夹着的牛皮纸，里面每人一张白色小卡片（职责头像贴纸、名字、Lv、红马克笔血条、「你」红章），下面「角色资料 / 武器 / 背包」 | 只剩一列头像 |
| 右上「工具」点开 | 牛皮纸卡片：地图、战绩、钱包与商店、任务日志、NPC 资料、申请检定、新画面开关（点了就收起） | 平时不显示 |
| 右边 | 战斗记录 / 小队聊天：上面两张牛皮纸索引标签切换；战斗记录是一长条热敏收据（打印体、虚线分隔、「本回合合计」），小队是贴在纸上的便利贴（自己发的靠右） | 只剩右边缘一个竖着的小标签「记录 · 聊天」，有新消息盖红章数字 |
| 底下中间 | 技能栏：撕下来的一长条牛皮纸（订书钉、胶带），纳米仪表、技能吊牌（打孔虚线、右上角「攻 / 技」小圆章、快捷键数字、用不了的划掉）、「唤出武器人」「结束行动」是瓦楞纸板 + 喷漆字 | 只剩一行「技能 ▲ 瑞比 · 轮到你了」 |

所有面板都稍微歪一点（±0.5～3°）、边是撕的 / 剪歪的、阴影不均匀，像纸片贴在沙盘上。收起 / 展开状态记在这台电脑上。

## 白天 / 夜晚 / 天气

- 白天：牛皮纸、米白卡片、白色收据（样稿 `shot-day.jpg`）。
- 夜晚：深色牛皮纸、黑卡纸，字是浅色（样稿 `shot-night.jpg`）。
- 天气给纸加一层色调 / 质感：沙暴 = 纸边发黄、落着沙粒；下雨 = 偏蓝灰、深色水渍；雪 = 偏冷白、边上一层霜；雾 = 偏灰、对比低一点。

## 实现提醒

- 纹理用 canvas / SVG 程序生成，按尺寸缓存，不要每次重排都重画；减少动态效果时打开收起不做动画。
- 文字、数字一定要清楚：印章、喷漆的斑驳只是一点点，不能糊到认不出（样稿里调过一次）。
- 联机玩家的数据照旧只走 `online-view.js` 的白名单；坚毅生命（shp / shpMax）绝不显示。
- 手机竖屏：队伍只显示头像一列；记录 / 聊天从底下拉出来盖满屏幕；技能栏在最底下。
