## 原始记录与复现

[evaluation-evidence.zip](evaluation-evidence.zip) 内：

- `matrix-timeout-diagnostics.json`：49 场逐种子结果、原/延长上限、两次终态及末轮日志。
- `campaign-timeout-diagnostics.json`：5 局对应未决战斗及其成长、策略保留说明。
- 对应的 `matrix-formal.json`、`campaign-formal.json`：原始正式样本，分母与分类保持不变。

解压到 `docs/r1/` 后，在仓库根目录运行：

```sh
node docs/r1/diagnose-timeouts.js docs/r1/matrix-formal.json --max-rounds 100
node docs/r1/diagnose-timeouts.js docs/r1/campaign-formal.json --max-rounds 100
```

脚本只把诊断 JSON 写到标准输出。默认拒绝源码哈希不一致的报告；`--seed` 可选一个完整种子。若显式使用 `--allow-source-mismatch`，结果只是当前代码的新诊断，不能称为历史结果复现。改变正式上限需要另行固定条件并完整重跑，不能选择性替换超时场次。
