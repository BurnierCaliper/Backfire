# HD-2D 战场原型（第一阶段 + 第二阶段 · 一）

「八方旅人」那种 HD-2D 的方向：2D 角色站在 3D 小场景里，加景深、光影、粒子。角色暂时没有立绘，**用铭牌代替角色**。
这是一个独立的原型页面，**不改任何正式游戏文件**；规则用的是真规则（`BattleSim.setup`）。
画面只用**联机玩家拿得到的数据**：房主的完整战斗状态先过一遍 `online-view.js` 的白名单（`OnlineView.projectState`），再交给布局和场景（见下面「第二阶段 · 一」）。

## 怎么打开

three.js 用 ES 模块，浏览器不让 `file://` 直接加载模块，所以要起一个本地静态服务（在仓库根目录）：

```
python3 -m http.server 8000
# 然后打开 http://localhost:8000/prototypes/hd2d/index.html
```

- 切换演示战场：右上角下拉框，或者网址后面加 `?demo=mine` / `?demo=desert` / `?demo=cross`
- 切换区域（默认地台的地面、远景、灯跟着变）：右上角第二个下拉框，或者网址后面加 `?region=沙漠`（区域名，或者地图地点 id，如 `?region=mine_3`；写一个认不得的名字，如 `?region=?`，看兜底的样子）。三个演示默认分别在第一采矿场、沙漠、外城区；切换时网址跟着改，复制网址就能回到同一个画面，例如 `?demo=cross&region=巨人城`
- **三段镜头**：顶栏的「镜头 远 / 中 / 近」三个按钮、键盘 `1` / `2` / `3`、滚轮（往前滚拉近、往后滚拉远，一次滚动跳一段）。点一个区的地台或者区里的铭牌就选中这个区（地台顶面亮一圈细框，顶栏写着「3 区 · 高压」），中景 / 近景看的就是它；中景 / 近景里左右键或者屏幕两边的箭头换到相邻的区。网址跟着记 `?cam=near&zone=3`，截图时复制网址就能回到同一个镜头，例如 `?demo=cross&cam=near&zone=3`
- 鼠标：左键拖动小幅转动、右键拖动平移（角度、平移范围都有限制，每一段的俯角范围不同）；鼠标停在铭牌上高亮并展开详细（等级、ATK、血量数字、状态），点一下选中（只是画面，不接规则），点空地取消
- 手机：单指转动，双指平移（不缩放，用顶栏的远 / 中 / 近）；窗口比较窄（竖屏）时战场整块转 90°，直排沿前后排开，铭牌才看得清
- 面板：底部「技能」栏、左边「队伍」栏、右边「日志」抽屉都能收起（手机默认全收起，只露一条 / 一个按钮）；点队伍栏里的人可以换当前行动单位
- 需要能用 WebGL 的浏览器

- 站位：按屏幕算——同一排横向至少隔开一块铭牌宽，前后排在屏幕上叠到就把后排整排抬高，铭牌下面一根细杆连到脚下（任意两块铭牌不重叠）
- 天气：`state.weather`（雷鸣 `thunder` 不下雨：乌云 + 随机雷击；酸雨 `acid` 照旧下雨）
- **坚毅生命（shp）的具体数值不显示**：`plateData` 只读白名单字段，压根不碰 shp；测试里给每个单位塞上特殊的 shp 数，确认铭牌数据里找不到

## 测试

```
node --test tests/hd2d-layout.test.js     # 或者 npm test
```

覆盖：各种棋盘（两区 / 三区 / 四区直排、2×2、十字；横屏和竖屏）下区不重叠且留缝、同区单位站位不重叠且不出地台、深渊区地面单位不压在黑洞上、飞行比地面高、下潜沉下去、场地 → 地台样子、铭牌数据里没有 shp；脚本语法检查。

第二轮加的：

- **铭牌不重叠**：测试里另写一个透视投影（不用布局里的），按布局给的镜头把每块铭牌投到屏幕上（像素尺寸 × 远近缩放、抬高、浮动幅度），两两比——各种棋盘同一区 4 人、挤 6 / 8 / 9 人（敌我混站、有飞行的）、1440×900（技能栏展开 / 收起）、1920×1080、1280×720 都不重叠；三个演示战场在桌面 1440×900 下两两不重叠、都在顶栏和技能栏之间
- **原型页面不报错**：`tests/hd2d-fake-page.js` 在 Node 里搭一个最小的假网页，照 `index.html` 的顺序跑垫片 → 规则文件 → 布局，`app.js` 的 `init()` 跑完 0 个报错；换回旧垫片能复现 `app.js:13680`（partySize）和 `app.js:8568`（bladeSel 的 options）
- **3D 积木**：在 Node 里用 vendor 的真 three.js 把各种地台、间隔、远景（含雷鸣的乌云）、天气 / 飘浮物都建一遍，跑几帧动画（含「减少动态效果」停住的一帧）；中景剪影的顶都在画面上沿那条视线以下

   - 现在：雷鸣不生成雨粒子（`WEATHER.thunder` 没有 `kind`，只有雾色和 `storm`），只有**乌云**和**随机雷击**。乌云：天幕换成压暗的风暴色，盖上两层慢慢飘的厚云（星星被盖住），中景上方再挂一层半透明的低云，乌云下平时的灯光压暗到八成。雷击：间隔 4–10 秒随机，七成劈在远处（低云前面、楼群之间），三成劈在战场后沿外面（地上亮一团）；闪电是带分叉的发光带子（芯 2.5px、外圈光 18px），一道雷连闪三下，全屏往白推、灯光推亮、云被照亮，一秒内退干净；同时镜头轻微抖一下（远处 2.5px、战场边缘 6px，0.45 秒退掉，只挪渲染、不动玩家的视角）。闪光频率 / 间隔 / 抖动幅度在 `hd2d-weather.js` 的 `STORM`，闪白强度在 `hd2d-scene.js` 的 `FLASH`，乌云在 `hd2d-backdrop.js` 的 `BACKDROP.storm`。飘浮物换成风卷起来的尘。酸雨（`acid`）照旧下雨，没动
   - 减少动态效果：雷照打（按真实时间数），但只闪一下、亮度只到 35%，镜头不抖；乌云停住
7. **路灯大幅减少**（截图验收后主人的反馈：「场地上有很多路灯比较奇怪」）
   - 以前：`hd2d-world.js` 的装饰里，每块不是沙地的地台都放 1 盏路灯，35% 再放 1 盏（酸液地台是绿灯、深渊是红灯），满场都是路灯，前 5 盏还带点光源
   - 现在：地台上一盏都不放。整场最多 2 盏（`CONFIG.lamps.max`），立在最后面那排地台的后角外面的地上，当氛围光；放几盏、放什么按地图写在配置表里（`GROUNDS[].lamps`，白天 / 傍晚 / 夜晚各几盏）：外城区 / 巨人城 / 天网设施是路灯（白天 1 盏，傍晚 / 夜里 2 盏），下水道是吊灯，三个采矿场各一盏矿灯（木架子吊一盏带铁笼的灯），沙漠不放；认不得的区域白天 1 盏、夜里 2 盏路灯。灯照旧偶尔闪一下，「减少动态效果」时不闪
   - 地台上其余的装饰（管道、废铁、石块）位置没变（去掉路灯时照样抽掉当时用的随机数）
8. **默认场地跟着地图换材质**（同一次反馈：「默认场地如果可以跟着地图走改变材质就更好了」）
   - 以前：没有场地效果的地台都是同一种水泥砖 + 油渍贴花，地台外面一片棕色废土，远景由演示写死（`backdrop`）
   - 现在：按这场战斗所在的区域选一套地面（区域名用游戏里现成的，地图地点 id 也认；对应表见上面「对应关系」）：顶面贴图、侧面材质、贴花、小石子 / 石块颜色、地台外大片地面的颜色、远景都跟着换（沙漠 → 沙丘，采矿场 → 两侧台阶状的岩壁 + 原来的矿井架 / 烟囱，城市 → 楼群，白天 / 傍晚也能用，楼的高低按区域；天网设施 → 沙丘里的一座天网塔）。只是垫高的高地也算默认场地（台阶跟着换）；酸液、电、冰、流沙、珊瑚、深渊、火、能量 / 谐波 / 治疗这些有场地效果的（包括和高地叠在一起的）照旧用自己的样子。找不到区域时是以前的样子（远景照旧按光影主题挑）
   - 原型页：顶栏加了区域下拉框，网址可以加 `?region=沙漠`；三个演示默认分别在第一采矿场、沙漠、外城区（以前演示用 `backdrop` 指定远景，现在由区域定）
   - 联机：查过了，玩家收到的战斗状态里没有区域名（见下面「区域名从哪来」），留给 #204；这一轮没改联机

## 第二阶段 · 一（issue #204）：三段镜头 + 只用联机玩家能拿到的数据来画

这一轮只看桌面宽度（1440×900），手机没专门调（能切、没弄坏）。只改了 `prototypes/hd2d/` 和对应的测试，正式游戏的文件一个没动。

1. **三段镜头，玩家自己切**（`hd2d-camera.js`，数值都在 `CAMERA`）
   - 远景：就是以前的样子（布局的默认镜头 `fitView`：俯角 30°、视野 22°，景深、雾、拖动范围全照旧），整个战场的沙盘全貌
   - 中景：俯角 22°、视野 24°，框住选中的区，再把每个相连的区各框进来一半（直排中间的区：左右各半个；十字中间：四条臂各半个；十字的一条臂：自己 + 半个中间区）；离得多远由框住的范围定，但至少是近景的 1.6 倍、至多是远景的 0.8 倍（十字的臂只连着一个区，光按范围算会推得和近景差不多近）。跟着当前行动单位 / 选中的区
   - 近景（看单个区域）：俯角 14°（接近平视）、视野 28°，只框选中的那一个区连同它放大的铭牌，区占画面宽八成多。景深焦点落在这个区：后面 / 前面的区按深度糊掉；同一排左右的区和它差不多远，光按深度糊不掉，场景给 BokehShader 加了一项「横着离开焦点区多远再糊一层」（`dof.lateral`，远景 / 中景是 0，和以前一样）
   - 切换：顶栏「镜头 远 / 中 / 近」三个按钮；滚轮在三段之间跳（`OrbitControls` 不再缩放；一次滚动只跳一段，触控板的惯性也只算一次）；键盘 `1` / `2` / `3`；点一个区的地台（三维里按射线找是哪个区）或者区里的铭牌就选中这个区（地台顶面靠边亮一圈细框，顶栏写「3 区 · 高压」），近景看的就是它；中景 / 近景里左右键或者屏幕两边的箭头换到相邻的区（顺序：后排到前排、同一排从左到右，到头停住）
   - 过渡：位置、朝向（俯角 / 方位）、视野、看的那一点、景深焦点和糊的程度、雾、近裁剪面、铭牌的抬高一起插值，0.5 秒，进出都慢的三次缓动；镜头的位置始终按「看的那一点 + 距离 + 俯角」算，不会直线穿过地台；从玩家拖动过的位置平滑出发，正在过渡时再切也从当前位置接着走。系统开了「减少动态效果」时不插值，直接切过去
   - 到了以后照样能左键小幅转动、右键平移，俯角范围每一段不同（`tilt`），距离固定
   - 切镜头只是看，不接规则；镜头是每个人自己的：不写进战斗状态，也不发给别人（每个玩家各自切远 / 中 / 近、各自选区）

### 联机数据：画面用到的字段，投影里有没有

查了 `online-view.js · projectState / projectUnit` 的白名单：

| 画面要的 | 投影里 |
| --- | --- |
| 棋盘（区号、坐标、连接）、直排几区 | 有（`board`、`zoneMode`） |
| 每个区的场地：深渊、酸液、流沙、沙珊瑚、高地、火、冰、电、能量、谐波、治疗 | 有（`fields`，全在） |
| 间隔：类型（畅通 / 桥 / 危墙 / 机关门 / 空隙）、开关、耐久 | 有（`gaps`） |
| 单位：名字、等级、ATK（实际 ATK 在 `display.atk`）、分层血量、架势、状态（灼烧层数等）、失衡、濒死、飞行、下潜、藏起来 / 死了 / 合体后移出 | 有（`projectUnit`）；名字会被规范化（全角括号变半角） |
| 天气、回合 | 有（`weather`、`turnNo`） |
| 当前行动单位 | 战斗状态里没有，联机玩家从 `packet.view.currentUnitId` 拿（原型页是自己点的） |
| 坚毅生命 | **没有，也绝不能加** |
| **区域名**（默认地台的地面、远景、灯跟着它） | 有（`region`，#229）：只放行认得的区域名，地图地点 id 换成区域名。#204 时还没有 |
| **光影主题**（白天 / 傍晚 / 夜晚：天空、灯光、灯的盏数） | 有（`light`，#229）：只放行 `day` / `dusk` / `night`。默认跟着游戏时钟（单局也有时钟：本局的档案），主持人可以在战场配置里改。#204 时还没有 |

#204 时列出来要加进白名单的这两个字段，#229 加上了（怎么来、怎么改见上面「区域名从哪来」）：

1. `state.region`：这场战斗在哪个区域。开战时从单机来源写进战斗状态（单局 `Rogue.region(run)`、战斗原型的遭遇 `spec.region`、跑团 `LEDGER.place`），白名单只放行 `world-data.js · BATTLE_REGIONS` 认得的区域名（和 `hd2d-layout.js` 的 `REGIONS` / `REGION_ALIAS` 一一对上）
2. `state.light`：这场战斗的光影主题 `day` / `dusk` / `night`（枚举），默认跟着游戏时钟（`daylight.js` 一张表，规则的昼夜也用它）

原型页：读投影里的 `pv.region` / `pv.light`；投影里没有的时候再用页面选的兜底（选「认不得（兜底）」时主机不认、白名单不发，看到的就是以前的水泥地）。都不从房主的原始 state 读。
