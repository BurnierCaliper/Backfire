# HD-2D 战场原型（第一阶段 + 第二阶段 · 一、二）

「八方旅人」那种 HD-2D 的方向：2D 角色站在 3D 小场景里，加景深、光影、粒子。角色暂时没有立绘，**用铭牌代替角色**。
这是一个独立的原型页面，**不改任何正式游戏文件**；规则用的是真规则（`BattleSim.setup`）。
画面只用**联机玩家拿得到的数据**：房主的完整战斗状态先过一遍 `online-view.js` 的白名单（`OnlineView.projectState`），再交给布局和场景（见下面「第二阶段 · 一」）。

## 怎么打开

three.js 用 ES 模块，浏览器不让 `file://` 直接加载模块，所以要起一个本地静态服务（在仓库根目录）：

```
python3 -m http.server 8000
# 然后打开 http://localhost:8000/prototypes/hd2d/index.html
```

- 切换演示战场：右上角下拉框，或者网址后面加 `?demo=mine` / `?demo=desert` / `?demo=cross`
- 切换区域（默认地台的地面、远景、灯跟着变）：右上角第二个下拉框，或者网址后面加 `?region=沙漠`（区域名，或者地图地点 id，如 `?region=mine_3`；写一个认不得的名字，如 `?region=?`，看兜底的样子）。三个演示默认分别在第一采矿场、沙漠、外城区；切换时网址跟着改，复制网址就能回到同一个画面，例如 `?demo=cross&region=巨人城`
- **三段镜头**：顶栏的「镜头 远 / 中 / 近」三个按钮、键盘 `1` / `2` / `3`、滚轮（往前滚拉近、往后滚拉远，一次滚动跳一段）。点一个区的地台或者区里的铭牌就选中这个区（地台顶面亮一圈细框，顶栏写着「3 区 · 高压」），中景 / 近景看的就是它；中景 / 近景里左右键或者屏幕两边的箭头换到相邻的区。网址跟着记 `?cam=near&zone=3`，截图时复制网址就能回到同一个镜头，例如 `?demo=cross&cam=near&zone=3`
- 鼠标：左键拖动小幅转动、右键拖动平移（角度、平移范围都有限制，每一段的俯角范围不同）；鼠标停在铭牌上高亮并展开详细（等级、ATK、血量数字、状态），点一下选中（只是画面，不接规则），点空地取消
- **特写**（#237）：近景里双击一个单位（铭牌，或者地台上它脚下的站位），镜头推到它面前特写，它的铭牌再放大一点（别的铭牌变淡，压到它的藏起来）；滚轮往后、按 `2` / `1`、点「远 / 中」就退出特写（往后滚一下回到正常的近景，按 `3` / 点「近」也是）；左右换区、点别的区也退出。控制台里 `HD2D.sc.closeUp(单位 id)` 也行
- 手机：单指转动，双指平移（不缩放，用顶栏的远 / 中 / 近）；窗口比较窄（竖屏）时战场整块转 90°，直排沿前后排开，铭牌才看得清
- 面板：底部「技能」栏、左边「队伍」栏、右边「日志」抽屉都能收起（手机默认全收起，只露一条 / 一个按钮）；点队伍栏里的人可以换当前行动单位
- **演示出招**（#230）：技能栏右上角「原型」那一小块里的「演示出招」按钮（控制台里 `HD2D.strike()` 也行）。房主用规则结算一次当前行动的人的普通攻击（够不着就换我方别人；连按会轮流换目标），投影成联机玩家收到的包，画面只按这个包播攻击演出和伤害数字。见下面「第二阶段 · 二」
- 技能栏照正式战斗画面的样子（#238）：左边普通技能按钮（左上角属性、右上角攻击 / 技能），右边「唤出武器人」和「结束回合」两个大按钮；技能按钮、这两个大按钮现在都还是摆设（点了只弹提示）。见下面「#238」
- 需要能用 WebGL 的浏览器

- 灯：地台上不再放路灯。整场最多 `CONFIG.lamps.max`（2）盏，立在最后面那排地台的后角外面的地上（战场外缘，不在地台上、不在两块地台之间），默认镜头里看得见；一盏放右后角（主光从左上方来，右边补一点），两盏左右各一
- 间隔：`state.gaps`——桥（受损会缺板）、危墙（越破越矮）、机关门（关着 / 开着）、空隙（黑坑）、畅通（碎石路）
- 铭牌（紧凑版）：名字一行；状态小圆点 + 分层血条 + 架势菱形一行；右上角贴着一小块行动点 / 附赠（#238）；等级、ATK、血量数字、架势、行动点 / 附赠、状态文字悬停 / 选中时从头顶展开。我方绿边、敌方红边；脚下有接触阴影；飞行单位浮起来，下潜单位半透明、下半截蒙一层沙色
- 行动点 / 附赠（#238）：`ap` / `apMax` / `bonus` / `bonusMax`，画法照正式画面的单位卡（`unit-card.js`）：圆点 = 行动点、三角 = 附赠，画 max(上限, 现有) 个，还有的实心、用掉的空心 / 灰；配置物、装置、间隔、中立生物不画（照 `game.css`）
- 站位：按屏幕算——同一排横向至少隔开一块铭牌宽，前后排在屏幕上叠到就把后排整排抬高，铭牌下面一根细杆连到脚下（任意两块铭牌不重叠）
- 天气：`state.weather`（雷鸣 `thunder` 不下雨：乌云 + 随机雷击；酸雨 `acid` 照旧下雨）
- **坚毅生命（shp）的具体数值不显示**：`plateData` 只读白名单字段，压根不碰 shp；测试里给每个单位塞上特殊的 shp 数，确认铭牌数据里找不到

## 已知的限制

- 技能按钮、「唤出武器人」「结束回合」点了还不会出招（技能名、消耗、说明还是房主本机规则里的技能表，联机时由房主按 `projectActionMenu` 另发，接出招时再换；#238 只换了样子）；出招只有「演示出招」那一个按钮（普通攻击、自动挑目标，#230），不接选目标、联机
- 作者这边没有能跑 WebGL 的浏览器，**画面效果没有亲眼验证过**：布局、镜头和铭牌的屏幕位置是算出来、测过的；颜色、调色、景深、泛光、雾、乌云、闪电、各区域的地面贴图 / 颜色、中景 / 近景的俯角和景深这些「好不好看」的参数是按经验设的，看了效果再调上面那张表里的参数
- 铭牌不重叠是按每一段镜头的默认位置算的；玩家自己转很偏时，可能会有一点压到
- 远景剪影的高度是按远景镜头的画面上沿定的；中景 / 近景镜头低，剪影的上半截可能出画（近景里远处糊得厉害，看得出是背景）
- 手机没专门调：三段镜头在手机上能切，近景的放大铭牌按手机尺寸排，但没看过效果
- 「下水道」游戏里还没有这张图（ROADMAP 里的新敌人「下水道」还在等设定），地面主题先放在表里，现在只能用 `?region=下水道` 看；名字定了以后在 `REGIONS` 里对上

## 第二阶段 · 二（issue #230）：演示出招——攻击演出 + 伤害数字

方向照主人说的：**不做 3D 特效模型，用正式游戏现成的 2D 演出**（attack-fx.js 的贴纸风刀光 / 冲击星 / 弹道、hit-fx.js 的受击粒子），画在 3D 沙盘上面那层全屏画布上，位置跟着铭牌走。只改了 `prototypes/hd2d/` 和测试；attack-fx.js / hit-fx.js 原样加载，**一行没改**（没加参数）。

这一步做了：

1. **适配器**（`hd2d-fx.js`，纯函数）：attack-fx / hit-fx 要的是「单位在屏幕上的矩形」，正式游戏里是单位卡的 DOM 矩形（game.js / online-ui.js 的 `rectOf`）。这里换成按**这一刻的镜头**把 3D 铭牌投影到屏幕上（和布局 / 场景同一个公式 `L.plateRect`：按远近缩放、后排抬高、近景放大的那张按放大的尺寸），区 → 地台顶面四个角投影后的外框。场景给三个接口：`sc.lensNow()`（镜头位置、看的点、视野、画面大小）、`sc.plateOf(id)`（铭牌现在在哪、抬多高、是不是放大的）、`sc.zoneOf(id)`；适配器每次被问都重新投影，所以远 / 中 / 近切换、过渡、玩家拖动转过去，矩形都跟着变。矩形两种写法都给：attack-fx 要的中心 + 宽高（`{ x, y, w, h }`，y 在卡片高 42% 处，和 game.js / online-ui.js 一样）、HitFx.burst 要的 `left / top / width / height`。`track(id)` 给 attack-fx 的击倒红叉（它本来就有 `track` 参数：镜头动了红叉跟着铭牌走）；被打倒、从画面上拿掉的单位留在最后看到的地方
2. **演示出招**：技能栏右边一个按钮。
   - 房主那边（`hd2d-host.js · strike`）：先开战（和 `BattleSim.run` 一样），挑当前行动的人的普通攻击（够不着就换我方别人；下潜中 / 躲藏中的敌人规则不让选，不挑；连按轮流换目标；演示用：行动点不够就补上，只为了能反复按），`runSkill` 真的结算一次（再 `BattleSim.resolveQueues` 把协助格挡这些排队的处理完）。结算时规则弹的字（`spawnPopup`）照 game.js 记成演出带（`type: "pop"`，带那一刻的单位 `snap`），攻击演出照 game.js · `strikePlan` 挑（`AttackFx.resolve`：属性、隔几个区、几段），公开日志写「谁 · 用了什么」，拼成联机的结果包，过 `OnlineView.projectPacket`（收件人是普通玩家）= **联机玩家收到的那一份**
   - 画面这边（`hd2d-play.js · play`）：**只拿这个包**。`HD2DFx.cues(packet)` 排演出：谁打谁、招式、每一段主攻击打中谁、要弹的数字（只用包里投影过的 `value`）、谁被击倒（出招前站着、包里倒下了）、有没有格挡。然后 attack-fx 的 `windup`（出手）→ `travel`（弹道，范围招式画 `area`）→ 第一下打中的那一刻**铭牌换成包里的 state**（血条跟着掉，`pv = packet.state`，不再从房主的 st 投影）→ 每一段 `impact`（刀光 / 冲击星，多段左右交替）+ `HitFx.burst`（受击粒子）+ 这一段的数字，段与段之间隔 `FX.timing.hitGap`（走 `AttackFx.after`，跟着演出倍率）→ 格挡 `clash` → 击倒 `ko`（红叉跟着铭牌）
3. **纸片风伤害数字**（DOM，`#hd2d-pop` 一层，盖在受击粒子上面）：粗墨线描边 + 属性色 + 往下错开的墨色投影，像一张贴纸拍上去（歪一点、弹一下、停住、往上飘一点淡掉）。普通伤害按属性色；**大伤害**（规则的 `bigHitInfo(等级, 伤害)`，和房主 `spawnPopup` 判「大伤害」同一个公式，只用投影里的等级和伤害）数字后面加 `!!`、放大、垫一张米白贴纸底；**击破**是黑底胶带标签「击破 N」；**格挡**是全息青的「格挡」（包里 `fx.parried`）；治疗薄荷绿 `+N`；状态字（白名单里的弹字：灼烧、无效……）小一号。字号按铭牌在屏幕上的宽缩放（**近景放大的铭牌上数字大，远景小**）；几个数字同时出来时先在铭牌头顶左右错开，压到了就往上叠，顶到顶栏换旁边一列，**两两不压住**（连往上飘的那一截一起算）；铭牌不在画面里（近景看的是别的区）就不弹。系统开了「减少动态效果」时数字不弹不飘（attack-fx 自己也只留很短的一闪）

## 主人试玩反馈 · 五（issue #242）：区域场景的美术——采矿场、沙漠

#239 把区域下面再分了场景（战斗状态的 `state.scene` / 投影的 `pv.scene`），这一条给采矿场、沙漠的每个场景做一套自己的美术：地面（顶面贴图）、地台侧面、地台上的装饰、远景、光照 / 调色、环境动画。只改了 `prototypes/hd2d/` 和测试，正式游戏的文件一个没动。

### 怎么接进来（为了不和 #241 城市类撞车，美术都在新文件里）

| 文件 | 内容 |
| --- | --- |
| `hd2d-scene-art.js` | **登记处**（普通脚本，Node 里能 `require`）：美术包加载时 `HD2DSceneArt.add(pack)`，把自己的地面主题并进布局的 `GROUNDS`、把「区域 → 场景 id → 地面主题」并进布局的 `SCENES`（只认正式场景表里已经有的区域、场景 id）；布局一行没改，`groundOf(区域, 场景)` 查到的就是场景自己的那一套。共用文件里的挂钩找它转交给对应的美术包；还有几个共用的小工具：场景的光照怎么改（`lighting` / `applyLight`）、环境动画的节拍（`beat`：隔多久来一阵、每阵多久）和来回走的东西（`mover`：停多久、走多快、停在哪几处）、地台上能摆装饰的地方（`zoneSpots`） |
| `hd2d-scenes-mine.js` | **采矿场的美术包**：配置表（`PALETTE` 色调、`PIT` 矿坑、`AMBIENT` 环境动画的频率、`ART` 每个场景的装饰 / 远景 / 光照 / 环境动画、`GROUNDS` 地面主题、`SCENES` 区域 → 场景 → 地面主题）、canvas 贴图、地台上的装饰（`zonePlan` 纯函数算摆在哪）、远景（矿坑） |
| 挂钩 | `hd2d-world.js`：贴图 / 贴花也找美术包要；地台上的装饰交给美术包（接管了就不画以前的废铁 / 管道 / 石块）。`hd2d-backdrop.js`：天边画的远景、中景交给美术包，美术包可以说「地台外面那片地到哪为止」（`groundEdge`，后面是坑）。`hd2d-scene.js`：开战时换上场景自己的光照（`state.lit`，所有读光影主题的地方都读 `themeNow()`），把地面挪到坑边。`index.html`：在布局后面加载登记处和美术包 |

美术包不 import three.js：three.js 和画贴图 / 拼几何体的小工具由挂钩那边打包成 `KIT` 传进来。都是几何体 + canvas 程序贴图（低多边形、`flatShading`），没有图片文件；只读布局给的地台 / 战场范围，不碰单位数据（没有坚毅生命）。

**装饰不压住站位 / 铭牌**：布局排人时脚下最多站到站位区的边（地台边长的一半 − `pad`），挤的时候前后边带上也会站人，所以地台上的装饰只摆在左右两条边带上（离区中心至少 站位区半宽 + 脚下那一圈 `SPOT.foot` + 装饰的半径；挨着别的区的那条边，中间桥 / 墙 / 门接上来的那一段不摆；高地的台阶那一段不摆）和左右矮一截的台子上。战场周围的东西都在战场范围外面，后面的先让开灯（在灯后面）。
