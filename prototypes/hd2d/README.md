# HD-2D 战场原型（第一阶段）

「八方旅人」那种 HD-2D 的方向：2D 角色站在 3D 小场景里，加景深、光影、粒子。角色暂时没有立绘，**用铭牌代替角色**。
这是一个独立的原型页面，**不改任何正式游戏文件**；规则用的是真规则（`BattleSim.setup`）。

## 怎么打开

three.js 用 ES 模块，浏览器不让 `file://` 直接加载模块，所以要起一个本地静态服务（在仓库根目录）：

```
python3 -m http.server 8000
# 然后打开 http://localhost:8000/prototypes/hd2d/index.html
```

- 切换演示战场：右上角下拉框，或者网址后面加 `?demo=mine` / `?demo=desert` / `?demo=cross`
- 切换区域（默认地台的地面、远景、灯跟着变）：右上角第二个下拉框，或者网址后面加 `?region=沙漠`（区域名，或者地图地点 id，如 `?region=mine_3`；写一个认不得的名字，如 `?region=?`，看兜底的样子）。三个演示默认分别在第一采矿场、沙漠、外城区；切换时网址跟着改，复制网址就能回到同一个画面，例如 `?demo=cross&region=巨人城`
- 鼠标：左键拖动小幅转动、右键拖动平移、滚轮缩放（角度、距离、平移范围都有限制）；鼠标停在铭牌上高亮并展开详细（等级、ATK、血量数字、状态），点一下选中（只是画面，不接规则），点空地取消
- 手机：单指转动，双指缩放 / 平移；窗口比较窄（竖屏）时战场整块转 90°，直排沿前后排开，铭牌才看得清
- 面板：底部「技能」栏、左边「队伍」栏、右边「日志」抽屉都能收起（手机默认全收起，只露一条 / 一个按钮）；点队伍栏里的人可以换当前行动单位
- 需要能用 WebGL 的浏览器

- 间隔：`state.gaps`——桥（受损会缺板）、危墙（越破越矮）、机关门（关着 / 开着）、空隙（黑坑）、畅通（碎石路）
- 铭牌（紧凑版）：名字一行；状态小圆点 + 分层血条 + 架势菱形一行；等级、ATK、血量数字、状态文字悬停 / 选中时从头顶展开。我方绿边、敌方红边；脚下有接触阴影；飞行单位浮起来，下潜单位半透明、下半截蒙一层沙色
- 站位：按屏幕算——同一排横向至少隔开一块铭牌宽，前后排在屏幕上叠到就把后排整排抬高，铭牌下面一根细杆连到脚下（任意两块铭牌不重叠）
- 天气：`state.weather`（雷鸣 `thunder` 不下雨：乌云 + 随机雷击；酸雨 `acid` 照旧下雨）
- **坚毅生命（shp）的具体数值不显示**：`plateData` 只读白名单字段，压根不碰 shp；测试里给每个单位塞上特殊的 shp 数，确认铭牌数据里找不到

## 测试

```
node --test tests/hd2d-layout.test.js     # 或者 npm test
```

覆盖：各种棋盘（两区 / 三区 / 四区直排、2×2、十字；横屏和竖屏）下区不重叠且留缝、同区单位站位不重叠且不出地台、深渊区地面单位不压在黑洞上、飞行比地面高、下潜沉下去、场地 → 地台样子、铭牌数据里没有 shp；脚本语法检查。

第二轮加的：

- **铭牌不重叠**：测试里另写一个透视投影（不用布局里的），按布局给的镜头把每块铭牌投到屏幕上（像素尺寸 × 远近缩放、抬高、浮动幅度），两两比——各种棋盘同一区 4 人、挤 6 / 8 / 9 人（敌我混站、有飞行的）、1440×900（技能栏展开 / 收起）、1920×1080、1280×720 都不重叠；三个演示战场在桌面 1440×900 下两两不重叠、都在顶栏和技能栏之间
- **原型页面不报错**：`tests/hd2d-fake-page.js` 在 Node 里搭一个最小的假网页，照 `index.html` 的顺序跑垫片 → 规则文件 → 布局，`app.js` 的 `init()` 跑完 0 个报错；换回旧垫片能复现 `app.js:13680`（partySize）和 `app.js:8568`（bladeSel 的 options）
- **3D 积木**：在 Node 里用 vendor 的真 three.js 把各种地台、间隔、远景（含雷鸣的乌云）、天气 / 飘浮物都建一遍，跑几帧动画（含「减少动态效果」停住的一帧）；中景剪影的顶都在画面上沿那条视线以下
- **雷鸣不下雨**（截图验收后补的）：真的 three.js 场景里量顶点——雷鸣建不出雨丝 / 往下落的粒子，酸雨照旧有；天气配置表里雷鸣没有雨粒子（`weatherPlan("thunder").main` 是 null），只有乌云 + 雷击。雷击用固定种子跑 150 秒：间隔都在 `STORM.interval` 里而且是随机的，远处和战场边缘都劈过；每道雷闪白、连闪、一秒内退干净，镜头抖动不超过配置的幅度、边缘的比远处的重；「减少动态效果」时照打，但不抖、闪光不超过 `STORM.reduced.flash`、只闪一下。乌云：天幕四色都比平时暗、星星盖住、有低云，打雷时云被照亮、亮处跟着雷走；远处的雷劈在天幕和低云前面、画面里
- **路灯减少、地面跟着地图**（截图验收后主人的反馈，7 条，在没改的代码上都失败）：
  - 区域 → 地面主题：区域名取自 `rogue-data.js` 的 `regions` / `altRegions`，每个区域各有一套、互不相同；`world-data.js` 的地点 id（`mine_1`、`outer_city`……）、天网塔和区域名对到同一套；认不得的（没给、空的、`月球`、还没有地面主题的地点）兜底成以前的水泥地；各套的顶面 / 侧面 / 贴花 / 大片地面看得出不同，主人给的对应（外城区铁皮侧面、沙漠沙纹 + 岩层、采矿场矿渣 + 岩层、三采冷光、巨人城金属 + 格栅、天网设施发光接缝、下水道积水）都在
  - 默认地台换地面、有场地效果的不受影响：十字五区里默认的、只垫高的地台换了，酸液、电、高地 + 火的没换；每一种场地效果单独放或者和高地叠在一起，在沙漠 / 巨人城 / 三采 / 下水道都不换；地台的样子（kind）和高度不随区域变；认不得的区域和不给区域一样
  - 路灯：各种棋盘 × 每个区域 × 白天 / 傍晚 / 夜晚，灯的盏数等于配置、不超过 2 盏，不在任何地台上，在战场后沿外面，灯杆底和灯头都在默认镜头的画面里（顶栏和技能栏之间）；沙漠没有灯，采矿场最多一盏矿灯、没有路灯；外城区 / 巨人城 / 天网设施 / 下水道夜里有灯
  - 真的 three.js 里建一遍：默认地台的顶面 / 侧面 / 贴花跟着区域换，有场地效果的地台和不给区域时是同一套材质和贴花，认不得的区域就是以前的水泥地；地台和间隔上一盏灯都没有，整场的灯就是布局给的那几盏
  - 远景：沙漠 → 沙丘、采矿场 → 岩壁（矿井架还在）、城市 → 楼群（白天 / 傍晚 / 夜晚、雷鸣都建得出来）、天网设施 → 沙丘里的天网塔；巨人城的楼比外城区高
  - 原型页：顶栏有区域下拉框、认 `?region=`，三个演示默认在第一采矿场 / 沙漠 / 外城区，布局拿到页面选的区域和光影主题；手机上收起区域下拉框

## 已知的限制

- 第一阶段只是外壳：技能按钮点了不会出招，日志是规则生成的，不接真正的出招、选目标、联机
- 作者这边没有能跑 WebGL 的浏览器，**画面效果没有亲眼验证过**：布局、镜头和铭牌的屏幕位置是算出来、测过的；颜色、调色、景深、泛光、雾、乌云、闪电、各区域的地面贴图 / 颜色这些「好不好看」的参数是按经验设的，看了效果再调上面那张表里的参数
- 铭牌不重叠是按默认镜头算的；玩家自己把镜头拉远（最多 1.12 倍）或转很偏时，可能会有一点压到
- 「下水道」游戏里还没有这张图（ROADMAP 里的新敌人「下水道」还在等设定），地面主题先放在表里，现在只能用 `?region=下水道` 看；名字定了以后在 `REGIONS` 里对上

## 区域名从哪来（给 #204：接进正式战斗画面）

原型里区域是页面选的（`?region=`）。以后接进正式战斗画面时，同一张 `REGIONS` 表认这些来源（区域名、地图地点 id 都认）：

- **单机**：单局 `Rogue.region(run)`（区域名，幕间改走的采矿场也在里面）；战斗原型的遭遇 `GAME.lastEncounter.region`（`run.js` 的 `spec.region`）；跑团 `LEDGER.place`（地图地点 id，主持人在地图上标的队伍位置）
- **联机玩家收到的**：联机单局的 `packet.rogue.region`（`online-rogue.js · viewFor`，`online-view.js` 只做 `scrubHidden`）有区域名；联机跑团只有 `packet.view.map.place`（地图地点 id，主持人标的位置，不一定是这场战斗在哪）；**战斗状态 `packet.state`（`online-view.js · projectState` 的白名单）里没有区域名**
- 所以现在没有一个「跟着这场战斗走、单机和联机都一样」的区域名。留给 #204：开战时把区域写进战斗状态（例如 `state.region`，从上面的单机来源取），在 `online-view.js · projectState` 的白名单里放行（只认 `REGIONS` 里的区域名 / 地点 id）。这一轮没改联机

## 第一阶段打磨第二轮（issue #202）

1. **同一区的铭牌不再互相压住**
   - 以前：同一区按世界坐标排 2×2，同一列前后两人在屏幕上只差约 44px，铭牌却有约 54px 高（头顶还有状态徽章），后排的名字 / 血条 / 架势被盖住；看守两人横向隔约 105px，铭牌最宽 128px，叠在一起
   - 现在：铭牌固定 120×40px（手机 100×36），只放名字 / 状态小圆点 / 血条 / 架势，等级、ATK、血量数字、状态文字悬停或选中时从头顶展开。布局（`hd2d-layout.js`）有一个和场景同一套的透视镜头（`fitView`，场景不再自己算取景），按屏幕像素排：同一排相邻两人至少隔开一块铭牌宽（按区的前沿、后沿都量，取挤的那边），前后排叠到就整排往上抬，铭牌下面一根细杆连到脚下。地台 6.4 → 7.2，厚度 0.5 → 0.8（高地 1.3 → 1.6）
   - 当前行动者：金边 + 光晕 + 名字左边的小箭头（以前头顶的大箭头会压到后排的铭牌，去掉了），脚下的光圈换成会慢慢转的虚线圈
2. **远景看得出是什么**
   - 以前：镜头俯角 30°、视角 22°，画面最上沿也是往下 19° 看，天空进不了画面；剪影大多比画面能装下的高，只露出下半截，又贴着同色的地面，景深再一糊，就成了一团土
   - 现在：战场后面立一圈天幕，按默认镜头真正看得到的那一截画天空渐变（傍晚橙 → 粉 → 紫，带夕阳光晕和被照亮的云；沙漠土黄；夜晚深蓝 + 星星）；天边一圈画出来的远景（远处的厂区 / 桌山 / 城市天际线）；中景几何体的高度按「画面上沿那条视线在那里有多高」定（`frameTop`），整个轮廓都在画面里，越远越接近天边的雾色。采矿场的烟囱冒烟、顶上红灯一闪一闪。景深对远处单独夹一个上限（`THEMES.dofFar`），稍微出焦但轮廓认得出；夜晚保持原来的糊法（城市灯光的散景）
3. **画面质感**：OutputPass 后面加一层调色（色温、饱和、对比、暗部 / 亮部偏色、四角暗角、胶片颗粒，每个光影主题一套；以前的 CSS 暗角会把铭牌也压暗，去掉了）；主光从左上方斜着打下来，右后方加一盏轮廓光，地台上沿一圈细亮边，铭牌上沿也有一道轮廓光；接触阴影换成很实的核心 + 一圈软影；水泥地加了分叉的裂缝、油渍（带一点彩虹光）、碎石、褪色的黄线，再零散铺几块贴花和小石子；地台侧面按场地分砖墙 / 瓦楞铁皮 / 岩层；一直有一层慢慢飘的飘浮物（晴天是光里看得见的尘埃，沙暴的大团沙尘、雪天的冰晶、酸雨往上冒的孢子、雷鸣时风卷起来的尘……），点状粒子都换成软的圆点
4. **待机小动画**：铭牌各自错开节奏上下浮动 ±2px（布局算矩形时上下各让出这 2px）；路灯隔几秒闪一阵；酸液的泡泡此起彼伏、到顶破开留一圈涟漪；深渊洞沿的紫光一明一暗地呼吸，洞里往上冒一点紫雾；行动光圈慢慢转；悬停高亮、点击选中（脚下一圈白线）。系统开了「减少动态效果」时这些全停（动画时间不走，天气粒子停在原地，胶片颗粒不动；雷击见第 6 条），中途切换也跟着变

6. **雷鸣不下雨**（截图验收后主人要求）
   - 以前：雷鸣（`thunder`）和酸雨一样下 800 条雨丝，飘浮物是「雷雨的水雾」；闪电是一条 1 像素宽的线，多半还被天幕挡住，基本只看得到灯光一亮；「减少动态效果」时完全不打闪电
   - 现在：雷鸣不生成雨粒子（`WEATHER.thunder` 没有 `kind`，只有雾色和 `storm`），只有**乌云**和**随机雷击**。乌云：天幕换成压暗的风暴色，盖上两层慢慢飘的厚云（星星被盖住），中景上方再挂一层半透明的低云，乌云下平时的灯光压暗到八成。雷击：间隔 4–10 秒随机，七成劈在远处（低云前面、楼群之间），三成劈在战场后沿外面（地上亮一团）；闪电是带分叉的发光带子（芯 2.5px、外圈光 18px），一道雷连闪三下，全屏往白推、灯光推亮、云被照亮，一秒内退干净；同时镜头轻微抖一下（远处 2.5px、战场边缘 6px，0.45 秒退掉，只挪渲染、不动玩家的视角）。闪光频率 / 间隔 / 抖动幅度在 `hd2d-weather.js` 的 `STORM`，闪白强度在 `hd2d-scene.js` 的 `FLASH`，乌云在 `hd2d-backdrop.js` 的 `BACKDROP.storm`。飘浮物换成风卷起来的尘。酸雨（`acid`）照旧下雨，没动
   - 减少动态效果：雷照打（按真实时间数），但只闪一下、亮度只到 35%，镜头不抖；乌云停住
7. **路灯大幅减少**（截图验收后主人的反馈：「场地上有很多路灯比较奇怪」）
