# HD-2D 战场原型（第一阶段）

「八方旅人」那种 HD-2D 的方向：2D 角色站在 3D 小场景里，加景深、光影、粒子。角色暂时没有立绘，**用铭牌代替角色**。
这是一个独立的原型页面，**不改任何正式游戏文件**；规则用的是真规则（`BattleSim.setup`）。

## 怎么打开

three.js 用 ES 模块，浏览器不让 `file://` 直接加载模块，所以要起一个本地静态服务（在仓库根目录）：

```
python3 -m http.server 8000
# 然后打开 http://localhost:8000/prototypes/hd2d/index.html
```

- 切换演示战场：右上角下拉框，或者网址后面加 `?demo=mine` / `?demo=desert` / `?demo=cross`
- 鼠标：左键拖动小幅转动、右键拖动平移、滚轮缩放（角度、距离、平移范围都有限制）；鼠标停在铭牌上高亮并展开详细（等级、ATK、血量数字、状态），点一下选中（只是画面，不接规则），点空地取消
- 手机：单指转动，双指缩放 / 平移；窗口比较窄（竖屏）时战场整块转 90°，直排沿前后排开，铭牌才看得清
- 面板：底部「技能」栏、左边「队伍」栏、右边「日志」抽屉都能收起（手机默认全收起，只露一条 / 一个按钮）；点队伍栏里的人可以换当前行动单位
- 需要能用 WebGL 的浏览器

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 入口：界面外壳、按 `tests/headless.js` 里 `RULE_FILES` 的顺序加载规则文件、三个演示战场 |
| `hd2d-layout.js` | **纯函数**，不碰 three.js 和 DOM，Node 里能 `require`：棋盘 → 每个区的 3D 位置 / 大小、区之间的间隔、每个单位的站位、铭牌上要写的数据；还有**默认镜头**（`fitView`，场景直接照它摆）和每块铭牌在屏幕上的矩形（`tests/hd2d-layout.test.js` 测它） |
| `hd2d-scene.js` | three.js 场景：镜头 / 主光 + 轮廓光 / 雾 / 后期（景深、泛光、热浪、调色）、铭牌（CSS2DRenderer 的 DOM，竖立、正面朝镜头）、接触阴影、行动光圈、悬停 / 选中、「减少动态效果」 |
| `hd2d-backdrop.js` | 远景：战场后面一圈天幕（天空渐变）、天边一圈画出来的远景、中景剪影（采矿场的矿井架 / 烟囱 / 传送带 / 筒仓，沙漠的沙丘 / 岩柱 / 桌山 / 船骨，夜晚的楼群 / 水塔 / 天线）、废土地面 |
| `hd2d-world.js` | 沙盘地台（侧面砖 / 铁皮 / 岩层，上沿一圈亮边）、地面贴花（裂缝 / 油渍 / 碎石）、桥 / 危墙 / 机关门 / 空隙、废铁 / 管道 / 路灯、酸液 / 深渊等场地的动画（全是几何体 + canvas 程序纹理，没有图片） |
| `hd2d-weather.js` | 天气粒子：沙暴、雪、酸雨、雷鸣（雨 + 闪电 + 闪光）、酷暑（热浪扭曲 + 火星）、微光、相位；一直在的飘浮物（晴天的尘埃，各天气各有各的） |
| `hd2d.css` | 界面：水泥 / 铁皮面板、喷漆按钮、胶带标签，名字和按钮用黑体加粗；紧凑铭牌 |

用到的东西：`vendor/three/`（three.js 0.160.0 本地副本，不走 CDN）里的 EffectComposer、RenderPass、BokehPass（景深）、UnrealBloomPass（泛光）、ShaderPass（热浪、调色）、OutputPass、OrbitControls。字体用 `fonts/fonts.css`。

## 对应关系（战斗状态 → 画面）

- 区的排法：`state.board`（特殊棋盘：2×2、十字、四区直排）；没有就按 `state.zoneMode` 当直排
- 地台样子：`state.fields[区]`——酸液（发绿光的液面）、流沙（旋转的沙涡）、深渊（地台中间的黑洞）、高地 / 沙珊瑚台地（地台更高）、火、冰、电（电火花）、能量 / 谐波 / 治疗（发光圈）；认不得的用普通水泥地
- 间隔：`state.gaps`——桥（受损会缺板）、危墙（越破越矮）、机关门（关着 / 开着）、空隙（黑坑）、畅通（碎石路）
- 铭牌（紧凑版）：名字一行；状态小圆点 + 分层血条 + 架势菱形一行；等级、ATK、血量数字、状态文字悬停 / 选中时从头顶展开。我方绿边、敌方红边；脚下有接触阴影；飞行单位浮起来，下潜单位半透明、下半截蒙一层沙色
- 站位：按屏幕算——同一排横向至少隔开一块铭牌宽，前后排在屏幕上叠到就把后排整排抬高，铭牌下面一根细杆连到脚下（任意两块铭牌不重叠）
- 天气：`state.weather`
- **坚毅生命（shp）的具体数值不显示**：`plateData` 只读白名单字段，压根不碰 shp；测试里给每个单位塞上特殊的 shp 数，确认铭牌数据里找不到

## 调参数

| 想调的 | 在哪 |
| --- | --- |

| 天幕离战场多远、天空渐变的位置、天边远景多高、中景剪影的范围和高度上限、烟和红灯 | `hd2d-backdrop.js` 的 `BACKDROP` |

## 测试

```
node --test tests/hd2d-layout.test.js     # 或者 npm test
```

覆盖：各种棋盘（两区 / 三区 / 四区直排、2×2、十字；横屏和竖屏）下区不重叠且留缝、同区单位站位不重叠且不出地台、深渊区地面单位不压在黑洞上、飞行比地面高、下潜沉下去、场地 → 地台样子、铭牌数据里没有 shp；脚本语法检查。

第二轮加的：

- **铭牌不重叠**：测试里另写一个透视投影（不用布局里的），按布局给的镜头把每块铭牌投到屏幕上（像素尺寸 × 远近缩放、抬高、浮动幅度），两两比——各种棋盘同一区 4 人、挤 6 / 8 / 9 人（敌我混站、有飞行的）、1440×900（技能栏展开 / 收起）、1920×1080、1280×720 都不重叠；三个演示战场在桌面 1440×900 下两两不重叠、都在顶栏和技能栏之间
- **原型页面不报错**：`tests/hd2d-fake-page.js` 在 Node 里搭一个最小的假网页，照 `index.html` 的顺序跑垫片 → 规则文件 → 布局，`app.js` 的 `init()` 跑完 0 个报错；换回旧垫片能复现 `app.js:13680`（partySize）和 `app.js:8568`（bladeSel 的 options）
- **3D 积木**：在 Node 里用 vendor 的真 three.js 把各种地台、间隔、远景、天气 / 飘浮物都建一遍，跑几帧动画（含「减少动态效果」停住的一帧）；中景剪影的顶都在画面上沿那条视线以下

## 已知的限制

- 第一阶段只是外壳：技能按钮点了不会出招，日志是规则生成的，不接真正的出招、选目标、联机
- 作者这边没有能跑 WebGL 的浏览器，**画面效果没有亲眼验证过**：布局、镜头和铭牌的屏幕位置是算出来、测过的；颜色、调色、景深、泛光、雾这些「好不好看」的参数是按经验设的，看了效果再调上面那张表里的参数
- 铭牌不重叠是按默认镜头算的；玩家自己把镜头拉远（最多 1.12 倍）或转很偏时，可能会有一点压到

## 第一阶段打磨（issue #191）

- 铭牌改成 DOM（`CSS2DRenderer`）：竖立、正面朝镜头、下边缘贴脚下，名字基准 13px（手机 12px）；按离焦点的远近缩放 / 变淡；状态徽章浮在铭牌头顶；当前行动者铭牌描金边，头顶跳动的箭头，脚下一圈发光光圈。站位横向间距 1.9、排距 1.6，相邻单位前后错开（`CONFIG.unit.stagger`）
- 加了远景和废土地面（`hd2d-backdrop.js`）；演示战场用 `backdrop` 指定远景（`mine` / `desert` / `night`，不指定按光影主题猜）；夜晚的星空画在天空贴图里
- 镜头：默认俯角 30°，取景边距 0.97，景深加强（`DOF`）
- 手机：危墙矮而薄（`hd2d-world.js` 的 `WALL`）；顶栏只显示「R1 · 晴 · 第一采矿场」，下拉框换成「换场」小按钮
- 页面里补上 `game.html` 那样的垫片（`index.html` 里的 `OWN` 是页面自己的 id 前缀），修掉 `app.js` 的 `init()` 找不到 `presetSelect` 的 null 报错；没动 `app.js`

## 第一阶段打磨第二轮（issue #202）

这一轮只看桌面宽度（1440×900），手机没专门调（布局照样能排，没弄坏）。

1. **同一区的铭牌不再互相压住**
   - 以前：同一区按世界坐标排 2×2，同一列前后两人在屏幕上只差约 44px，铭牌却有约 54px 高（头顶还有状态徽章），后排的名字 / 血条 / 架势被盖住；看守两人横向隔约 105px，铭牌最宽 128px，叠在一起
   - 现在：铭牌固定 120×40px（手机 100×36），只放名字 / 状态小圆点 / 血条 / 架势，等级、ATK、血量数字、状态文字悬停或选中时从头顶展开。布局（`hd2d-layout.js`）有一个和场景同一套的透视镜头（`fitView`，场景不再自己算取景），按屏幕像素排：同一排相邻两人至少隔开一块铭牌宽（按区的前沿、后沿都量，取挤的那边），前后排叠到就整排往上抬，铭牌下面一根细杆连到脚下。地台 6.4 → 7.2，厚度 0.5 → 0.8（高地 1.3 → 1.6）
   - 当前行动者：金边 + 光晕 + 名字左边的小箭头（以前头顶的大箭头会压到后排的铭牌，去掉了），脚下的光圈换成会慢慢转的虚线圈
2. **远景看得出是什么**
   - 以前：镜头俯角 30°、视角 22°，画面最上沿也是往下 19° 看，天空进不了画面；剪影大多比画面能装下的高，只露出下半截，又贴着同色的地面，景深再一糊，就成了一团土
   - 现在：战场后面立一圈天幕，按默认镜头真正看得到的那一截画天空渐变（傍晚橙 → 粉 → 紫，带夕阳光晕和被照亮的云；沙漠土黄；夜晚深蓝 + 星星）；天边一圈画出来的远景（远处的厂区 / 桌山 / 城市天际线）；中景几何体的高度按「画面上沿那条视线在那里有多高」定（`frameTop`），整个轮廓都在画面里，越远越接近天边的雾色。采矿场的烟囱冒烟、顶上红灯一闪一闪。景深对远处单独夹一个上限（`THEMES.dofFar`），稍微出焦但轮廓认得出；夜晚保持原来的糊法（城市灯光的散景）
3. **画面质感**：OutputPass 后面加一层调色（色温、饱和、对比、暗部 / 亮部偏色、四角暗角、胶片颗粒，每个光影主题一套；以前的 CSS 暗角会把铭牌也压暗，去掉了）；主光从左上方斜着打下来，右后方加一盏轮廓光，地台上沿一圈细亮边，铭牌上沿也有一道轮廓光；接触阴影换成很实的核心 + 一圈软影；水泥地加了分叉的裂缝、油渍（带一点彩虹光）、碎石、褪色的黄线，再零散铺几块贴花和小石子；地台侧面按场地分砖墙 / 瓦楞铁皮 / 岩层；一直有一层慢慢飘的飘浮物（晴天是光里看得见的尘埃，沙暴的大团沙尘、雪天的冰晶、酸雨往上冒的孢子、雷雨的水雾……），点状粒子都换成软的圆点
4. **待机小动画**：铭牌各自错开节奏上下浮动 ±2px（布局算矩形时上下各让出这 2px）；路灯隔几秒闪一阵；酸液的泡泡此起彼伏、到顶破开留一圈涟漪；深渊洞沿的紫光一明一暗地呼吸，洞里往上冒一点紫雾；行动光圈慢慢转；悬停高亮、点击选中（脚下一圈白线）。系统开了「减少动态效果」时这些全停（动画时间不走，天气粒子停在原地，不打闪电，胶片颗粒不动），中途切换也跟着变
5. **脚本报错**：垫片的 `OWN` 以前按前缀匹配，`partySize` 被 `party` 拦下拿到 null（`app.js:13680`）→ 改成逐个列出页面自己的 id、整个匹配。修完这个，`init()` → `renderAll()` → `syncBladeSel()` 还会在 `app.js:8568` 遍历 `bladeSel.options` 报错（替身 div 没有 options）→ 照 `game.html` 在隐藏的 `#calc-core` 里放一个真的 `<select id="bladeSel">`。其余 `init()` 用到的 40 多个元素都拿到替身。没动 `app.js`
