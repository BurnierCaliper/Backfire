# HD-2D 战场原型（第一阶段）

「八方旅人」那种 HD-2D 的方向：2D 角色站在 3D 小场景里，加景深、光影、粒子。角色暂时没有立绘，**用铭牌代替角色**。
这是一个独立的原型页面，**不改任何正式游戏文件**；规则用的是真规则（`BattleSim.setup`）。

## 怎么打开

three.js 用 ES 模块，浏览器不让 `file://` 直接加载模块，所以要起一个本地静态服务（在仓库根目录）：

```
python3 -m http.server 8000
# 然后打开 http://localhost:8000/prototypes/hd2d/index.html
```

- 切换演示战场：右上角下拉框，或者网址后面加 `?demo=mine` / `?demo=desert` / `?demo=cross`
- 鼠标：左键拖动小幅转动、右键拖动平移、滚轮缩放（角度、距离、平移范围都有限制）
- 手机：单指转动，双指缩放 / 平移；窗口比较窄（竖屏）时战场整块转 90°，直排沿前后排开，铭牌才看得清
- 面板：底部「技能」栏、左边「队伍」栏、右边「日志」抽屉都能收起（手机默认全收起，只露一条 / 一个按钮）；点队伍栏里的人可以换当前行动单位
- 需要能用 WebGL 的浏览器

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 入口：界面外壳、按 `tests/headless.js` 里 `RULE_FILES` 的顺序加载规则文件、三个演示战场 |
| `hd2d-layout.js` | **纯函数**，不碰 three.js 和 DOM，Node 里能 `require`：棋盘 → 每个区的 3D 位置 / 大小、区之间的间隔、每个单位的站位、铭牌上要写的数据（`tests/hd2d-layout.test.js` 测它） |
| `hd2d-scene.js` | three.js 场景：镜头 / 灯光 / 雾 / 后期、铭牌（CSS2DRenderer 的 DOM，竖立、正面朝镜头）、阴影 |
| `hd2d-backdrop.js` | 远景和废土地面：采矿场（矿井架 / 烟囱 / 传送带 / 矿渣堆）、沙漠（沙丘 / 岩柱 / 桌山）、夜晚（楼群灯光 + 星空）；放在景深焦点外，自然糊开 |
| `hd2d-world.js` | 沙盘地台、桥 / 危墙 / 机关门 / 空隙、废铁 / 管道 / 碎石 / 路灯（全是几何体 + canvas 程序纹理，没有图片） |
| `hd2d-weather.js` | 天气粒子：沙暴、雪、酸雨、雷鸣（雨 + 闪电 + 闪光）、酷暑（热浪扭曲 + 火星）、微光、相位 |
| `hd2d.css` | 界面：水泥 / 铁皮面板、喷漆按钮、胶带标签，名字和按钮用黑体加粗 |

用到的东西：`vendor/three/`（three.js 0.160.0 本地副本，不走 CDN）里的 EffectComposer、RenderPass、BokehPass（景深）、UnrealBloomPass（泛光）、ShaderPass（热浪）、OutputPass、OrbitControls。字体用 `fonts/fonts.css`。

## 对应关系（战斗状态 → 画面）

- 区的排法：`state.board`（特殊棋盘：2×2、十字、四区直排）；没有就按 `state.zoneMode` 当直排
- 地台样子：`state.fields[区]`——酸液（发绿光的液面）、流沙（旋转的沙涡）、深渊（地台中间的黑洞）、高地 / 沙珊瑚台地（地台更高）、火、冰、电（电火花）、能量 / 谐波 / 治疗（发光圈）；认不得的用普通水泥地
- 间隔：`state.gaps`——桥（受损会缺板）、危墙（越破越矮）、机关门（关着 / 开着）、空隙（黑坑）、畅通（碎石路）
- 铭牌：名字、等级、分层血条、架势菱形、状态徽章、ATK；我方绿边、敌方红边；脚下有椭圆影子；飞行单位浮起来，下潜单位只露半截、半透明
- 天气：`state.weather`
- **坚毅生命（shp）的具体数值不显示**：`plateData` 只读白名单字段，压根不碰 shp；测试里给每个单位塞上特殊的 shp 数，确认铭牌数据里找不到

## 调参数

镜头角度、景深、光影主题在 `hd2d-scene.js` 顶部的 `CAM` / `DOF` / `THEMES`；地台大小、站位间距在 `hd2d-layout.js` 的 `CONFIG`；天气粒子数量 / 速度 / 颜色在 `hd2d-weather.js` 的 `WEATHER`；装饰和灯的数量在 `hd2d-world.js` 的 `WORLD`。

## 测试

```
node --test tests/hd2d-layout.test.js     # 或者 npm test
```

覆盖：各种棋盘（两区 / 三区 / 四区直排、2×2、十字；横屏和竖屏）下区不重叠且留缝、同区单位站位不重叠且不出地台、深渊区地面单位不压在黑洞上、飞行比地面高、下潜沉下去、场地 → 地台样子、铭牌数据里没有 shp；另有一条脚本语法检查（three.js 部分要 WebGL，Node 里跑不了）。

## 已知的限制

- 第一阶段只是外壳：技能按钮点了不会出招，日志是规则生成的，不接真正的出招、选目标、联机
- 作者这边没有能跑 WebGL 的浏览器，**画面效果没有亲眼验证过**（景深强度、泛光阈值、铭牌大小、取景边距都是按经验设的，看了效果再调上面那些参数）

## 第一阶段打磨（issue #191）

- 铭牌改成 DOM（`CSS2DRenderer`）：竖立、正面朝镜头、下边缘贴脚下，名字基准 13px（手机 12px）；按离焦点的远近缩放 / 变淡；状态徽章浮在铭牌头顶；当前行动者铭牌描金边，头顶跳动的箭头，脚下一圈发光光圈。站位横向间距 1.9、排距 1.6，相邻单位前后错开（`CONFIG.unit.stagger`）
- 加了远景和废土地面（`hd2d-backdrop.js`）；演示战场用 `backdrop` 指定远景（`mine` / `desert` / `night`，不指定按光影主题猜）；夜晚的星空画在天空贴图里
- 镜头：默认俯角 30°，取景边距 0.97，景深加强（`DOF`）
- 手机：危墙矮而薄（`hd2d-world.js` 的 `WALL`）；顶栏只显示「R1 · 晴 · 第一采矿场」，下拉框换成「换场」小按钮
- 页面里补上 `game.html` 那样的垫片（`index.html` 里的 `OWN` 是页面自己的 id 前缀），修掉 `app.js` 的 `init()` 找不到 `presetSelect` 的 null 报错；没动 `app.js`
